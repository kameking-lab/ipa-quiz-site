## エグゼクティブサマリ

9.5 割完成という自称に対し、実勢は 6〜7 割。骨格（/search ファセット、/mock-exam 試験区分
セレクター、/study-plan ウィザード、個別問題ページの構造化データ、再訪時パーソナライズ）は
狙い通り動作する一方、検索流入を取り切れない SEO 構造の冗長性、初訪問者を取りこぼす
オンボーディングの強制度、信頼性を毀損する数値の不整合、競合比 16 倍遅い TTFB など、
「研ぎ澄まし」の名に値しない構造的欠陥が残存する。

本フェーズ（10）は **致命傷 5 件 + 即修正 9 件** を全件潰す。追加機能はゼロ。
削除・統合・修正のみで「研ぎ澄まし」に到達させる。

## 致命傷（5 件）

### 致命傷①: SEO 構造の冗長・矛盾（C-2 / C-3 / C-5）
個別問題ページに **QAPage + Quiz + LearningResource + BreadcrumbList**（実機では
さらに FAQPage も）の 4〜5 スキーマが同居し、Google に冗長判定されてリッチリザルトを
取りこぼしている（C-2）。さらに:
- **C-5**: meta description が「正解は{X}。」を front-load しており、SERP 上で答えが
  ネタバレ → クリックする動機を削ぐ（CTR 低下要因）。
- **C-3**: `robots.txt` で `/account/` を Disallow している一方、ヘッダーの「学習進捗」
  リンクが `/account/dashboard` を指しており、クロール指示と内部導線が矛盾。
  あわせて `robots.txt` に 2018 年廃止の非標準ディレクティブ `Host:` が残存（即修正⑧と重複）。

### 致命傷②: （①の SEO 構造修正に内包）
致命傷① の C-2 / C-5 / C-3 を独立タスク（フェーズ10 タスク②③④）に分解して対応する。

### 致命傷③: AI 生成コンテンツの開示不足
`/success-stories`（合格体験記）と `/essays`（論文）は **AI 生成の架空ペルソナ** だが、
タイトル直下に小さく注記があるのみで、実在の合格者・実在の論文と誤認させるリスクが高い。
景品表示・体験談規制の観点でも危うい。タイトル同等の視認性で警告を出し、検索インデックス
からも外すべき。

### 致命傷④: 公称問題数の不整合
公開問題総数の表記が場所によって **14,402 / 14,000 超 / 12,573 / 12,652** とバラバラ。
ホーム・検索・各試験 LP・ブログ末 CTA で異なる数字が出ており、サイト全体の信頼性を毀損。
単一情報源（single source of truth）への集約が必須。

### 致命傷⑤: TTFB が競合比 16 倍（C-6）
過去問道場 51ms に対し、過去問AI は 540〜806ms。個別問題ページのキャッシュ戦略・
静的生成・ISR 設定・初期データ取得の見直しで 200ms 以下を目指す。

## 即修正（9 件）

- **即修正①（G-2 関連 / 結論第二）**: AI 生成コンテンツ（合格体験記・論文）の開示を
  タイトル同等サイズ・赤系警告色で明示（致命傷③と連動）。
- **即修正②（A-2）**: `/search` プレースホルダ「SQL注入」は中国語訳語。日本語サイトとして
  不適切 →「SQLインジェクション」へ。釣り（0 件ヒット）になっているキーワードも実ヒット語へ。
- **即修正③（A-1 / A-3 / 結論第三）**: 着地と同時のオンボーディング強制表示を廃止し、
  CTA クリック時のみ起動。初訪 3 秒で「何のサイトか」が分かる導線へ。「3分体験」と
  「3問だけ試す」の意味重複も解消。
- **即修正④（D-4 / F-1）**: AI 類題マッチングが分野破綻（可変長符号化に音声サンプリングを
  提示）。細分野タグでのマッチングとフォールバック表示を追加。
- **即修正⑤（D-4 / F-1）**: AI 回答長「5行」設定でも 10 行超を出力。設定が機能していない。
  プロンプトでの行数制約を明示するか、機能しないなら設定 UI を撤去。
- **即修正⑥（D-2）**: AI 上限バッジの条件表示を削除したと主張する一方、コパイロット内で
  「残り 10/10 回」が明示されており矛盾。表記を単一定数で統一。
- **即修正⑦（D-1）**: 報告 UI を 3→1 に削減と主張する一方、コメント欄（0/800）が報告
  兼用で残存。コメント欄を「補足・別解の共有」専用に再定義し、報告はインラインボタンに一本化。
- **即修正⑧（C-3）**: `robots.txt` の `Host:` ディレクティブ（2018 年廃止・非標準）を削除。
  標準準拠の `robots.txt` に整理。
- **即修正⑨（G-2）**: 主要 CTA「今すぐ解く」のコントラスト比 3.00 は WCAG AA（4.5:1）違反。
  「未挑戦」バッジ 2.23、「初心者おすすめ」4.35 も同様に AA 達成へ。

## 改善優先度マトリクス（要旨）

- **高（即修正・ユーザー獲得直結）**: CTA コントラスト（⑧）、オンボーディング強制緩和（⑩）。

  AI 上限表記（⑬）、コメント欄役割（⑭）、robots 標準準拠（⑮）。

## 結論

- **第一**: SEO 構造（スキーマ重複・ネタバレ description・robots 矛盾）が検索流入の最大の
  ボトルネック。これを解消しないと、コンテンツ量（公開 1.2 万問超）の優位を活かせない。
- **第二**: AI 生成コンテンツの開示不足と公称問題数の不整合は、サイトの信頼性に直結する
  即時リスク。
- **第三**: 初訪問オンボーディングの強制度が、せっかくの流入を入口で取りこぼしている。
- 総じて「実務レベルで使える」が、上記の構造的欠陥を潰すまでは「研ぎ澄まし完成」を
  名乗れない。フェーズ10 で 14 件全件を潰し切ることが、6〜7 割から完成度を引き上げる条件。
