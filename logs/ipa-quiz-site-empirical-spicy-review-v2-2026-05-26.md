### A-4 /admin エラーページ整備（反証 / 退行）
`/admin` および `/admin/` への fetch は `AbortController` で8秒/10秒の上限を設けても両方とも `AbortError`、TTFB が10秒超で応答せず。同タブでブラウザナビゲーションすると Chrome の「ERR_HTTP_RESPONSE_CODE_FAILURE」相当のエラーフレーム表示（スクリーンショット撮影が `Frame is showing error page` で失敗）。フェーズ11の「カスタム404 or 認証画面 or 削除済」主張に対し、実機は **無限待機/タイムアウト**。

仮説: middleware で /admin/* を `/auth/*` にリダイレクトしている際に `next/headers` の cookies() を読みつつサーバ側ループに陥っている、もしくは Edge Function でレスポンスを `return` していない。GoogleBot から見ると Soft 404 / Crawl Error が積み上がるパターン。**反証 / 致命的**。

## F. 新たな実機特有の穴（構造レビューで見えない領域）

最低5件の要件に対し、本レビューで**9件**新規検出。

**F-1: /admin の無限待機（実機特有）**
fetch /admin が10秒AbortError、ブラウザ直接アクセスでもエラーフレーム。middleware設計のサーバ側ループ疑い。GoogleBot がここに来るとクロール予算を浪費 + Soft 404 計上。**致命的**。

**F-2: クイズUIの role=radio 完全欠落（実機特有）**
`/quiz?mode=random&exam=ap` で：
- `[role=radio]`: 0個
- `[role=radiogroup]`: 0個
- `input[type=radio]`: 0個
- 選択肢は `<button class="group relative w-full ...">` で tabindex=0 のみ

スクリーンリーダーには「ボタン」と読み上げられ「ラジオボタン」として認識されない。矢印キーによる選択肢間ナビ（roving tabindex）も実装ゼロ。フェーズ12の「role=radio roving実装」主張は**完全反証**。アクセシビリティ規定（WAI-ARIA Authoring Practices）違反。

**F-3: 試験LPとブログ記事の問題数不整合（実機特有）**
/ip = 2,381問 / /blog/ip-nani-kara-benkyou = 2,398問。**17問の差**。Phase 11の「公称問題数の単一情報源化」と矛盾する数値混入。ブログ記事生成時の古いデータかコピペ初出値。

**F-4: コールドTTFB 500–700msの構造的遅延（実機特有）**
過去問道場 14ms に対し 40–50倍劣後。Vercel Edge + Next.js RSC + Supabase の組合せで、RSC payload 生成と関連問題のクエリ（おそらく `topicTags` ベースじゃない別経路）が原因。SEO上、Googleの "Slowest URLs" レポートに乗りやすく、コアアップデートで順位が下落するリスク。

**F-5: クイズページの skip-link 欠落（実機特有）**
`a[href="#main"]` / `a[href="#content"]` / `[class*=skip]` のいずれもDOMに存在せず。キーボードユーザはヘッダーのタブ（過去問AI/問題を解く/模試/検索/ブックマーク/学習進捗/推薦書籍/設定/問題種別タブ等）を毎ページTab連打する必要あり。WCAG 2.4.1 Bypass Blocks 未対応。

**F-6: お問い合わせ form の input[name] 欠落（実機特有）**
`お名前`/`メール`/`本文` の input/textarea の `name` 属性が空。Server Action経由のFormData送信は内部的に動くが、Form Submitイベントを拾う外部解析（GA4, Hotjar など）からは「フィールド名なし」と認識される。コンバージョン計測上の盲点。

**F-7: 「プロジェクトの考え方： /about」生URL露出（実機特有）**
/contact 冒頭ガイド: `先にご確認いただきたいページ ・プロジェクトの考え方： /about` という表示で、リンク表示テキストが「/about」という生URL。日本語ラベル（例: 「過去問AIについて」）でないため、UX上の素人っぽさが残る。

**F-8: localStorage キーの命名規則分裂（実機特有）**
`kakomon-ai-user-context-v1`（ハイフン形式）と `ipa-quiz:streak:probe:v1`（コロン形式）と `ipa-quiz:study-days:v1`（コロン＋ハイフン混在）が同一プロジェクト内に同居。今後のキー削除や移行で grep 漏れが起きやすい。

**F-9: 学習カレンダーaria-label「学習なし」の冗長性（実機特有）**
365日分のセル全てに `aria-label="2025-05-27: 学習なし"` 形式で付与。学習活動がほぼゼロの新規ユーザはスクリーンリーダーで365回「学習なし」を聞かされる。`<table>` セマンティクス + 単一の summary を読ませる方が情報密度的に妥当。
