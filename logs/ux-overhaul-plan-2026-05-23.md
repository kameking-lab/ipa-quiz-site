# ipa-quiz-site UX徹底改修計画 2026-05-23

## エグゼクティブサマリ（社長向け、15行以内）

- 現状診断：「初見でも触れるレベル」には到達しているが、ナビゲーション・情報設計・モバイル対応に致命的な穴が複数あり、説明文に依存して動く設計になっている。
- 致命的な摩擦トップ3：
  1. グローバルナビが「問題を解く / 学習進捗 / 推薦書籍」だけで、検索・ブックマーク・模試・学習計画・体験記が全てメニューから到達不能（モバイルは更に学習計画/検索/体験記/機能/whyへの導線ゼロ）。
  2. /search の初期表示は検索窓のみで、絞り込み（試験区分/年度/分野/難度）が「検索実行後」にしか出ない。説明文と実態が乖離し3秒テストで「これでは絞り込めない」と判断される。
  3. 「分野で集中演習したい（例：ネットワーク）」導線が無い。トップの「ネットワーク」は NW 区分カードであり、AP の中の "ネットワーク分野" を解く方法は問題演習中の "苦手分野を克服" ボタン経由でしか発見できない。
- 推奨改修の総工数感：P0（即着手・小工数）で 5〜8人日、P1 で 2〜3人週、P2 で 1人月程度。全体 1.5〜2ヶ月で UX 完成度を一段引き上げ可能。
- 改修後の期待効果：初訪問→1問目到達のクリック数 平均4→2、トップから「分野指定演習」到達 不可能→2クリック、検索の初期離脱率を体感40%→10%程度まで圧縮、モバイル経由 PV の機能到達率を倍増。

## ページ別診断

### 1. / （トップ）
- 3秒テスト：◯（「どの試験を受けますか？」が大見出し、無料/登録不要バッジ、AI解説デモが目に入る）
- 次の一手テスト：△（IP/SG の緑CTAと、その下の13枚のカードのどちらを押すべきか視線が迷う。CTA階層が同格）
- 主要タスクのクリック数：AP 1問目まで 実測2クリック / 理想2クリック ＝合格
- 検出された問題：
  - 初訪問でスクロール開始すると突然 onboarding モーダルが被さる（フォールド下から登場し意図せず起動）。ステップ3で「次へ」が disabled だが視覚的にほぼ判別不能。
  - onboarding の「スキップして閉じる」が左下に枠付き、「次へ」が右下に塗り。CTA階層は正しいが枠付きスキップが目立ちすぎ。
  - 「IPを解いてみる/SGを解いてみる」緑CTA と直下の13カードが同一視認重量。初心者は IP/SG カードを2回押す事故が起きやすい。
  - 学習カレンダーが空のままページ下部に常駐。初訪問者には情報価値ゼロで離脱要因。
  - ヘッダーのナビが3項目だけで、検索・ブックマーク・模試へ到達できない。
- 推奨改修：
  - onboarding は初訪問時のみ1回、スクロール前に表示。途中復活させない（クリック数削減：0、迷い解消：大）。
  - 「IP/SG緑CTA」を13カードの上から外し、13カードに "初心者おすすめ" バッジで包含。CTAの二重化を解消（迷い解消：大、視線一本化）。
  - 学習カレンダーは履歴0件のとき非表示にし、代わりに /quickstart へのリンクを置く（情報密度低下、初訪問の余白確保）。
  - ヘッダーに 検索🔍 / ブックマーク🔖 / 模試📝 を常時露出（クリック数：1で全機能到達）。

### 4. /quiz （実質的には個別問題演習ページ）
- 3秒テスト：△（問題本文より先に上部の5モードタブ＋"モード: random" の英字が目に入り、何のページか直感で分かりにくい）
- 次の一手テスト：△（右ペインに AI クイックアクション12個＋プリセット質問5個が並び、左の問題よりも視覚的重量が大きい。初心者は AI を先に押そうとする可能性が高い）
- クリック数：1問解答→次の問題まで 実測2クリック（選択→次の問題へ） ＝及第点
- 検出された問題：
  - "モード: random" という英字ラベルがそのまま表示。日本語UIに英語の値が混在し、初見で違和感。
  - AI コパイロットパネルが右に固定で、画面横幅の約40%を常時占有。問題と回答コストを比較すると、AIに目が行きやすい。
  - 「読み上げ x1.00」「キーボード: 1〜4で選択 / Rでスター / ?でヘルプ」がフッター付近に小さく置かれ、上級者にも初心者にも届かない位置。
  - 1問目から「不正解時にバッジ獲得トースト」が画面下に出るが、最初の1問では褒める文脈が空回り（"はじめの一歩" と書かれる）。
- 推奨改修：
  - "モード: random" は「ランダム出題（応用情報・全80問）」と日本語化（迷い解消：中）。
  - AI コパイロットを右ペイン常駐から「右下フローティング → タップで展開」に変更（モバイルと同等パターン）。問題への集中度UP。
  - クイックアクション12個は初期 表示を6個までに絞り「さらに見る」で展開。AI に投げる選択肢を半減させて学習行動を主役にする（迷い解消：大）。
  - キーボードヘルプを ? アイコンとして問題エリア右上に常駐表示（発見性UP）。

## シナリオ別診断

### シナリオA：応用情報を受けるので過去問を解きたい
- 完走可能性：◯（自然）
- 詰まりポイント：0回
- クリック数：実測 2クリック（トップ→APカード→ランダム出題で解く）
- 改善ポイント：トップで「IP/SG緑CTA」と「13カード」が二重CTAになっており初心者の視線が迷う。緑CTAを廃し、AP・FE カードに直接 "今すぐ解く" 副ボタンを足せば1クリックで開始可能。

### シナリオB：ネットワーク分野を集中的に練習したい
- 完走可能性：△（可能だが迷う）
- 詰まりポイント：3回（トップの "ネットワーク" カードは NW 区分であって分野ではない／問題演習ページに分野指定UIなし／間違えた後の "苦手分野を克服" ボタン経由で初めて分野演習に到達）

## 全体方針提案

ナビゲーション再設計：グローバルヘッダは現状3項目（問題を解く / 学習進捗 / 推薦書籍）と歯車のみで、機能の半分が埋もれています。「問題を解く / 模試 / 検索 / 学習計画 / ブックマーク / 進捗」を主導線に昇格し、推薦書籍は二次メニューに降格すべきです。モバイルメニューも同等の項目を持たせ、現状到達不能な /search /bookmarks /study-plan /success-stories /features /why-kakomon-ai /essays を全て露出します。

共通コンポーネント：ヘッダはモバイルでも下端固定の "底タブ" 風（問題 / 模試 / 検索 / 進捗 / メニュー）にすると、片手操作で全機能到達できます。フッターは現在5列ですが情報過多なため、初訪問時は折りたたみ表示にして "もっと見る" で展開。AI残10回の浮きバッジがフッターのリンクと被って隠す問題があるので、AIバッジは右端から少し内側、フッターより上に固定する設計に。

LocalStorage活用：初訪問判定で onboarding を1回だけ表示、2回目以降は完全非表示。学習履歴がある場合、トップを「どの試験を受けますか?」ではなく「続きから（最後に解いた問題）」+「今日のおすすめ5問」に変えるパーソナライゼーション。受験予定区分が設定されていれば、トップ全体をその区分に最適化（IPユーザーに ST/PM カードを見せない）。

AIコパイロット起動UI改善：PCでは右ペイン常駐を廃し、画面右下のフローティング球＋"AIに聞く" ラベル化、タップで右からスライドイン。これによって問題への集中度が大幅にアップし、AIに頼りすぎない学習を促進。クイックアクションは「よく使う6個」を既定にして "+他11個" で展開、ユーザーがピン留めできる仕組みも検討。

## 競合との比較

- 過去問道場：圧倒的な蓄積した人力解説と無料広告モデル。過去問AIは AI コパイロットの "対話的深掘り" で勝負できるが、初学者には「人力解説の安心感」が依然強い。差別化メッセージを /why ページ以外(トップなど)に明確に露出すべき。
- Studyplus 系：学習記録・SNS要素が強い。過去問AIは LocalStorage 主義で SNS には踏み込まないが、進捗カードに「友人と比較」ではなく「同じ試験区分の平均ストリーク」のようなパーソナル指標があると差別化可能。
- 通信講座：金額の壁。過去問AIは「完全無料 + AI添削β」で十分差別化できているが、UI 上で "AI午後採点" や "業種別論述事例" を初訪問の3秒以内に伝えきれていない。トップに3秒で読めるバッジを追加すべき。
