# SC 2023春期 改善版プロンプト仕様

## 作成日: 2026-05-10

## 品質問題の背景

2023春期5業種答案（内部不正対策とアクセス制御）が総合3(NO-GO)と判定。
字数不足（1,503〜1,746字）が主因。2,200字目安に対して25〜35%不足。

## 改善版プロンプト（必須出力指示）

SC論文答案生成時に以下をすべて含めること:

### 1. 字数要件
- 全体 2,200字以上2,500字以下（intro + body + conclusion の合計）
- 設問ア（intro）: 350〜450字
- 設問イ（body）: 1,200〜1,500字
- 設問ウ（conclusion）: 550〜600字（全体の25%以上を必ず確保）

### 2. 設問ウ（conclusion）の必須要素
- 定量的な成果を2件以上明記（数値・割合・件数・日数等）
- 残存課題を2件以上列挙
- 今後の改善計画を2件以上述べる
- 字数は550字を下回らない

### 3. 設問イ（body）の推進困難セクション
- 困難を「一つ目」「二つ目」と明示して2件以上記述
- 各困難について「実施した対応」「残課題または追加施策」を両方記述
- 単なる解決済み事例ではなく、改善途中の課題も含めること

### 4. 定量効果の明記
- body・conclusionを通じて定量数値を合計2件以上記述
- 例: 「誤報率45%→8%（2か月後）」「アクセス件数47件→5件（89%削減）」
- 「大幅に」「著しく」などの定性表現だけでは不可

### 5. 業種固有の制度・規制名の引用
- 業種固有の制度・規制・ガイドライン名を3件以上明示的に引用
- 引用箇所は「○○法」「○○ガイドライン」「○○指針」の形式で正式名称を使う
- 汎用的な「個人情報保護法」のみでは不足（業種固有の制度を必ず含める）

### 6. 業種キャラクター設定の維持（必須）
- 既存の組織設定（規模・業種・事件の概要）を変更しない
- IT: A社（SIer 500名）の特権ID不正アクセス事案
- 金融: B地方銀行（預金量2.8兆円、1,600名）の顧客データ持ち出し事案
- 建設: C建設（売上3,200億円、2,800名）のBIM設計データ持ち出し事案
- 医療: D総合病院（820床、1,400名）の元看護師による診療情報不正閲覧・SNS投稿事案
- 公共: E市（人口38万人）の元職員による退職後の住民税情報不正閲覧事案

## 改善効果の検証方法

1. 全体字数: intro + body + conclusion の文字列長を計測 → 2,200字以上
2. conclusion比率: conclusion字数 / 全体字数 → 25%以上
3. 困難件数: body 内の「一つ目」「二つ目」の出現確認
4. 定量数値: 数値表現の件数カウント → 2件以上
5. 規制名: 固有名詞の引用件数カウント → 3件以上

## 適用対象

SC 2023春期「内部不正対策とアクセス制御の設計」（設問pm2-q1）
5業種: IT・金融・建設・医療・公共
