# 気象予報士65・66回 私的閲覧画面

この画面はローカルの私的検査専用です。78原問（学科60、実技18）と実技237回答欄を原本と対応付け、公開用ルートや一般の問題ローダーには登録していません。原本 `data/qualification-staging/kisho-65-66-private/raw-combined.json` はバイト保存し、第65回専門問4の説明6か所だけ、独立受入済みの `q04-overlay-accepted.json` を別ファイルから厳密に適用します。

1. 作業WT `C:\wt\qualification-kisho-private-20261020` で `pnpm exec vite --config scripts/kisho-private-reader/vite.config.ts` を実行します。依存は既存のものを使用します。buildは不要です。
2. 同じPCのブラウザで `http://127.0.0.1:4178/` を開きます。サーバーは `127.0.0.1` の固定ポート4178だけにバインドし、ポートが使用中なら起動しません。
3. 最初に私的PNG 130点を読み込みます。図表は原寸のまま各領域内をスクロールできます。学科は「答え合わせ」後に全5肢の理由を表示します。実技は欄ごとの試答を入力し、例解・根拠・公式解答画像を見て手動照合します。記述の自動採点はありません。
4. 「下書きを保存」で、このブラウザのlocalStorageへ選択肢、実技試答、手動照合済み印を保存します。表示を閉じても同じブラウザ・同じURLで読み戻します。別端末との同期や送信はありません。終了時は端末で Ctrl+C を押します。

サーバーが配信するPNGはmanifestに列挙したIDだけで、`/__kisho_asset/<ID>` を通じて読み込みます。`.env`、Git、reports、その他のprivate-assets直URLへのアクセスは拒否します。外部HTTP/API/モデル呼出はありません。原典権利の確認前のため画像・原文の公開、配信、共有には使用しません。
