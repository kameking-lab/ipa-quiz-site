## 2. NPS+50達成への壁分析

NPS +50 は「プロモーター 60%＋デトラクター 10%以下」が必要。現状の物理ボトルネック：

| 障壁 | 種類 | 解決可能性 |
|---|---|---|
| **AP午前 5年×80問＝400問**（過去問道場は2009年〜全年） | データ物理量 | 個人運用では現実的に不可。**解消不能** |
| **AP午後 実問題ゼロ**（モック3問のみ） | データ物理量 | IPA午後問はOCR＋人手検証必須。AI単独不可 |
| **Stripe決済未稼働** | 営業/技術 | 数日で解消可能 |
| **法人MSA/SLA不在** | 法務 | 個人事業主のままでは無意味 |
| **/demo/* 404** | 技術虚偽 | コード書けば解消、ただし支えるデータ無し |
| **解説「準備中」表示**（年次一覧UI） | UIバグ | 数時間で修正可能 |
| **運営者が個人事業主・法人未登記** | 信用上 | 法人化に2-4週＋資本金が必要 |

**結論: NPSを+50に上げるには「AP過去30年」と「法人化」の両方が必要だが、両方とも個人運用の物理限界を超える。** +50は**不可能**。
現実的な天井は **+10〜+20** が限度。

## 4. ビジネスモデル評価

### 4-1. 「量より質」戦略の妥当性
質（AI解説）は確かに過去問道場より新しい。しかし**学習者は「量」を先に必要とする**。1年に1回の試験で400問だけ解いて受かる学習者は皆無。質の差別化は量が揃った後の話。**戦略の前提が崩れている**。

### 4-2. Premium課金転換の現実性
- α無料・全機能解放中 → 課金開始時に「無料で全部使えてた」感の壁
- ¥980/月で50/日→500/日のAIコパイロット枠拡張のみ
- 弱点ヒートマップ・合格判定シミュレータは「Premiumで開放」と書かれているが**実装確認できず**
- **転換率予測：0.3〜1%**（業界平均下限）。1,000人来訪で月3〜10人。月¥3,000〜¥10,000の売上。サーバ/Geminiコスト割れ。

### 4-3. 法人営業の実体化
- /enterprise/pricing 404
- /legal/msa 404
- 運営者が個人事業主
- /trust 404（信頼性開示ページ無し）

→ **法人営業は実体ゼロ**。¥50,000×席数の見込み顧客に提示できる材料が無い。これは「机上のSKU」に過ぎない。

## 6. ローンチ可否最終判定

### 現状ローンチ → 失敗確率: 約 85%

理由：
1. AP午前が5年分しかなく、本気の受験者は1週間で消費して離脱
2. AP午後は「実問題ゼロ・モック3問」で看板倒れ
3. 法人プランは販売ページもMSAも無く受注不能
4. Stripe未稼働で個人課金もできない
5. Wave 2の差別化ページ10件が物理404

### 改善継続が必要なら最重要3項目（投資順序）

1. **AP午前データ拡充**（2009〜2022年の14年分・約1,120問の追加投入）
   - これが無ければ何をしても無駄。最優先。
2. **Stripe Checkout 本稼働 + Premium価値の実装**（弱点ヒートマップ等を実物で）
   - 個人課金を回し、月次MRRの実数値を取る

   - 売っていない物をメニューに置くな。誠実さの問題。

法人プランと SOC2 と /demo/* は**すべて削除**して、個人受験者向けに集中するのが正解。

## 8. 「過去問AIで独立する」の現実性

### 結論: 現状の延長線上では不可能。

**収益試算（楽観シナリオ）：**
- 月間アクティブユーザー 5,000人（過去問道場の1/100）
- Premium転換率 1%（業界上限）
- ¥980 × 50人 = **月¥49,000**
- Geminiコスト・Vercel・Neon・ドメイン・Stripe手数料引いて手取り **月¥10,000〜¥30,000**

**生計を立てるには月最低¥250,000必要。** 8〜25倍のスケールが要るが、AP400問で来る5,000人MAUを維持できる根拠が無い。

**独立条件として最低限必要なのは：**
1. 全13区分・各15年×80問＝**約15,600問の網羅**（現状12,162問だが内訳偏在・AP不足）
2. AP午後の実問題対応（IPA午後はPDF複雑・OCR不能箇所多数で人手必須・**個人で年200時間級**）
3. 法人化＆MSA＆SLA（資本金最低100万・税理士・登記）

これらを片手間で揃えるのは現実的に2〜3年仕事。**独立資金は最低500万円のキャッシュ**を用意できないなら**独立すべきでない**。

## 9. ANZEN AI に集中すべきか論争の最終結論

齋藤ナオの結論: **ANZEN AI に集中すべき。**

理由：
- 過去問AIは**競合（過去問道場）が17年積み上げた人力データ**に対し、AI差別化だけで殴っている。**勝てない**。
- ANZEN AI は AI セキュリティ という**競合がまだ確立していない領域**で、AIネイティブ運用が一次価値となる。**過去問AIより構造的に勝率が高い**。
- 過去問AI の「AI解説」「モバイルUX」のノウハウは ANZEN AI に転用可能。**過去問AIへの投資は無駄ではない**が、これ以上の機能追加は**機会費用が高すぎる**。

**過去問AIの扱い:**
1. 現状の404ページ・先付けSKUを全削除
2. AP午前をあと10年分だけ追加投入（¥0コスト・PDF抽出のみ）
3. その後は **凍結**。月1回の Gemini再生成バッチ程度のメンテに留める
4. 工数の80%を ANZEN AI に振る

過去問AIは「履歴書に書ける副業ポートフォリオ」の位置に格下げするのが正解。
