# 第二種電気工事士 過去問題利用状況の連絡準備

状態: **未送信・receiptなし**（2026-09-23 JST）。公開ステータスは `notification-required` のまま維持する。

電気技術者試験センターの[FAQ](https://www.shiken.or.jp/shiken/faq/faq08/000082.html)は、公表済み過去問題の教育利用に許諾・使用料は不要とし、出典・改変の明記と、所定7項目の利用状況メール連絡を求めている。送信先は `info@shiken.or.jp`。法人名・部署、担当者氏名、住所、電話番号、メールアドレス、使用する問題の試験名、使用目的を記す。`/operator` の公開表示から実名・住所・電話番号・返信メールは確定できないため、推測で補わない。

## 送信前に運営者が埋める4項目

- 担当者氏名
- 住所
- 電話番号
- 返信メールアドレス

「法人名・部署」は法人運営の場合は正式名称・部署名、個人運営ならその旨を正確に記入する。公開ページにある「ボランティア有志」等を法人名として扱わない。
