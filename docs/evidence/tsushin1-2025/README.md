# 令和7年度 1級電気通信工事施工管理技術検定・第一次検定

全国建設研修センター（JCTC）の原本形式の問題A・問題B・正答表の公開保存コピーを、[公開過去問索引](https://dobokujira.com/1denkitsushin-pastproblems/)から取得した。実際の取得元URL、ファイルサイズ、PDFページ数、SHA-256、表紙・正答表の確認結果は `complete/provenance.json` に記録する。現行のJCTC公式一覧には該当3資料が残っておらず、当時の公式PDFとのハッシュ一致、保存サイトの転載許諾・再利用条件は未検証である。保存コピーをJCTCから直接取得したとは扱わない。

表紙による原問数はA55問・B35問の90問。実試験での解答数はA33問・B27問、合計60問である。2026年度から母数を推定していない。全90問に原問・正答・4肢すべての学習用説明を収録し、2026年度90問と合わせて最新2回180原問とする。従来公開された2026年度12問は保持し、追加数は168問。学習用解説は本サイトが作成したもので、試験団体の公式解説ではない。

PDFの本文を毎回抽出する `scripts/extract_tsushin1_2025.py` はフォントと文字サイズを限定した、画像確認済みのマッピングだけを適用する。根拠は `complete/FONT-EXTRACTION-NOTES.md`。指数・添字・論理否定・波形・穴埋め表などの修復は `TRANSCRIPTION-OVERRIDES.json` に分離し、画像からの言語化は原本PNGと併記する。図表PNGには設問・選択肢を含め、原本ハッシュ・PDFページ・クロップ座標・画像ハッシュを `CROP-RECEIPTS.json` に保存する。

`python scripts/audit_tsushin1_latest_two.py` で2年度の問番号・全問本文・4肢・正答・全肢解説・出典・原本PDF・図版のハッシュを検査する。`complete/2026-PRESERVATION.json` で完成済み2026年度90問のファイルが変わっていないことを確認する。独立レビューは難問の局所確認に限定し、その範囲と結果を `TARGETED-INDEPENDENT-REVIEW.json` に残す。

既存スキーマの `JCTC-authorized-reuse` 識別子を引き継ぐが、それ自体を新たな許諾の証明とはしない。掲載可否は所有者が扱い、本作業では新たな権利・許諾の証拠を作成していない。本番merge・deployは統合主担当の担当である。
