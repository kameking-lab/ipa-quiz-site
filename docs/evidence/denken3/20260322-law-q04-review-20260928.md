# 令和7年度下期・第三種電気主任技術者 法規問4の再照合

- 公式問題：[法規PDF](https://www.shiken.or.jp/chief/upload/20260322_ch_third_q04.pdf) のPDF 8頁（紙面5頁）。5肢に図はなく、電圧・抵抗・時間・接地線径を原図で照合した。PDFテキスト抽出では `Ω` が落ちるため、原図の90 Ωと300 Ωを採用する。
- 公式正答：[解答PDF](https://www.shiken.or.jp/chief/upload/20260322_ch_third_a01.pdf) の法規列・問4は `(4)`。
- 出題基準日は問題PDF 4頁の注3にある2025年4月1日。解説の基準は経産省の[2024年10月22日版「電気設備の技術基準の解釈」](https://www.meti.go.jp/policy/safety_security/industrial_safety/sangyo/electric/files/20241022-2.pdf) 第17条・第29条と、同日施行の[省令第2条](https://laws.e-gov.go.jp/law/409M50000400052?occasion_date=20250401)。後日の統合版を当時の条文として扱わない。

## 肢別の照合

1. 200 V・90 Ω：低圧300 V以下はD種、第17条の原則100 Ω以下に収まる。
2. 100 V・乾燥場所：第29条第2項第1号は交流**対地電圧**150 V以下又は直流**使用電圧**300 V以下を要件とする。通常の100 V交流回路なら対地100 Vとして適用できる。一方、設問の「使用電圧100 V」だけから任意の交流結線の対地電圧は特定できない。この前提を公開解説にも明記する。
3. 440 V・0.1秒・300 Ω：低圧300 V超はC種。地絡時0.5秒以内に自動遮断する場合、第17条の500 Ω特例に収まる。
4. 水気のある場所・100 V・0.1秒・接地省略：第29条第2項第5号は「水気のある場所以外」の低圧用機械器具に限る。同項第1号は乾燥場所に限る。漏電遮断器の時間だけでは接地を省略できない。**不適切な肢**。
5. 3,300 V・直径2.6 mmの軟銅線：高圧はA種。第17条第1項第2号ロの線径下限を満たす。

第2肢の交流の結線条件は設問に明記されていないため、一般化を避けた。第4肢は水気のある場所という明示条件と第29条の例外範囲で判定できる。

電力問1は公式正答 `(3)` を原図で確認したが、選択肢の `(エ) 高落差を得にくい` の方式間比較を[JICA水力開発ガイドマニュアル第1分冊 3.2.2](https://openjicareport.jica.go.jp/pdf/0000256044_01.pdf)は直接裏付けていない。全空欄を根拠付きで説明できるまでは `official-summary` を維持する。
