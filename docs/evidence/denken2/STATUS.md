# 電験二種 一次試験 収録状況と受入契約

## 収録範囲（2026-09-26）

- 試験回：令和8年度 第二種電気主任技術者一次試験（2026-08-30実施）。公式の問題と解答の一覧（https://www.shiken.or.jp/chief/second/qa/）で公開済みの最新回。
- 収録科目：**電力（問1〜問7）と法規（問1〜問7）の2科目のみ**。理論・機械、過年度、二次試験は未収録。サイト上も「電力・法規」と明示し、「全科目」とは表示しない。
- 解答単位：公式の採点単位どおり、各問の空欄(1)〜(5)を1単位とする。2科目×7問×5空欄＝**70単位**。選択肢は公式解答群(イ)〜(ヨ)の15肢をそのまま使い、内部キー ア〜ソ に順番で対応させる（`lib/questions/display.ts`）。URLは `/q/denken2/2026-primary/{denryoku|houki}/q{問}-{空欄}`。

## 正本と再現手順

1. `docs/evidence/denken2/input/` に公式PDF 3本（電力 q02、法規 q04、解答 a01）を固定。SHA-256 は `scripts/denken2-source-manifest.json`。
2. `py -3.12 scripts/denken2-source-manifest.py` が解答PDFのテキスト層を列のx座標で読み、科目別に5空欄ずつ分割して manifest の `blanks` を作る。電力・法規とも35個を読み取り、頁画像の目視読取りとも一致した。
3. 原稿は `data/questions/denken2/reviewed/20260830-{power|law}-qNN.json`（1ファイル＝1問＝5行）。問題冊子の頁画像から文字起こしし、各空欄に正答理由と14の誤答理由（空欄が求める語の種類＋その肢が当てはまらない理由）を付けた。法規は問題冊子注3の基準日（令和8年4月1日）時点の法令・解釈で説明する。
4. `py -3.12 scripts/denken2-review.py` が問ごとに公式頁画像・解答表画像・公開図・候補5行を `claude-opus-5-5`（firstParty、ツール無効）へ渡して独立照合し、`docs/evidence/denken2/receipts/{stem}-opus.json` に候補行の正準SHA-256・PDF SHA・頁画像SHA・公式正答と判定を固定する。生応答は `docs/evidence/denken2/raw/`（`-text` 属性）。
5. `py -3.12 data/questions/denken2/build-launch.py` は、manifest の正答と一致し、かつ現行行のSHAに結び付いた PASS（全Issues空）レシートがある単位だけを `launch.json` に出す。1件でも欠ければ失敗する（`--check` で差分検知）。
6. `__tests__/questions/denken2-launch-data.test.ts` が 2紙・14問・70単位、PDF SHA、正答、15肢・15理由、レシートのSHA・モデル・生応答SHA、URLの一意性と往復、空欄順の前後移動、イロハ表示を検証する。

## 査読の経過

- 1巡目：14問中PASSは一部。主な指摘は、誤答理由が他の空欄向けの定型文になっている点、条文番号の誤記（電気事業法第54条の定期検査の主体等）、法規問7の「軽負荷期」の誤読、法規問2の図の説明不足、MACCの意味の取り違え、回線選択リレーの端子近傍事故の説明の逆転など。
- 2巡目以降：誤答理由を「空欄が求める語の種類（kinds）＋肢の中立的な説明（whats）＋紛らわしい肢の個別理由（specific）」に作り直し、指摘を反映。最終的に14問70単位すべてが現行SHAでPASS。
- 図：法規問2（A線の地図）と電力問3（P-V曲線）を公式PDFから図だけ切り出し `public/images/denken2/20260830/` に置いた。問題文にも図の文字説明を付けている。
