## 出典分類と掲載判断

出典は一般社団法人日本中小企業診断士協会連合会です。解説は独自作成です。
`JF-CMCA-attributed` は出典分類であり、利用許諾の取得や自由利用を表すライセンスではありません。
公式法的事項には事前承諾の条件、利用規約には商業利用の条件があります。
掲載可否はユーザー（サイトオーナー）が対応します。このタスクはdraft PRまでで、本番マージ・デプロイを行いません。
許諾済みとの記録は作成していません。
