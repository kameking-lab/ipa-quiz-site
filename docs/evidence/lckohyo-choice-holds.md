# 選択肢別解説の保留台帳

## 2025年・特級ボイラー技士の工学バッチ

`lckohyo-LC20251101` の最初の未整備5問（`q4`,`q5`,`q10`,`q11`,`q16`）は、政府一次資料で全肢を支えられず自動生成を採用していない。特に安全弁の構造・設定の固有数値は、e-Govボイラー則28条、厚労省の構造規格通知・報告書だけでJIS本文の値を確定できない。JISC原本にアクセスして該当箇所を確認するまで保留する。

`q11` の既存プレーン解説は、E肢のスートブロー「最大負荷50％以下」の説明が曖昧で、負荷条件の方向を十分に示していない。協会公式PDFの正答は(2)（A・Eが誤り）で確認済みだが、公開できる政府一次資料から50％の閾値そのものを確認できていないため、推測した「50％以上」へ機械的には書き換えない。根拠が得られてから既存解説と構造化解説を同時に訂正・再審査する。

確認候補： [e-Govボイラー則](https://laws.e-gov.go.jp/law/347M50002000033)、[厚労省ボイラー構造規格改正通知](https://www.mhlw.go.jp/web/t_doc?dataId=00tc9709&dataType=1)、[厚労省切替弁・構造規格通知](https://www.mhlw.go.jp/web/t_doc?dataId=00tb5708&dataType=1&pageNo=1)、[厚労省改正報告書](https://www.mhlw.go.jp/content/11201250/001556664.pdf)。各候補がどの肢の数値を直接支えるかの照合は未了。

## 2025年・第二種衛生管理者の未受入問題

`lckohyo-LC20252115` の Q18、Q19、Q25、Q29 は元の5問バッチから回収できていない。Q24 と Q26 も候補修正済みだが、独立レビューの最終PASSまでは未受入。候補資料の取得結果とSHAは [hold source index](./lckohyo-choice-hold-source-index-20260923.json) に記録した。URLを収録しただけでは、各肢への適用確認にならない。

- **Q18 骨折:** 厚労省の傷病名コード同義語表は「単純骨折＝閉鎖性骨折」「複雑骨折＝開放骨折」を示す。消防庁の応急手当資料は骨折部と上下の関節を副子で固定すると示す。肢(5)の完全骨折と軋轢音を直接支持する国の資料がまだ見つかっていないため、全肢解説は保留。
- **Q19 労働衛生統計:** 厚労省の調査は有所見率を「受診者のうち所見のある労働者の割合」と説明し、総務省統計局は分散・代表値・相関と因果の区別を説明する。肢(5)の病休度数率を100万延べ実労働時間当たりとする国の原典が未確認で、保留。
- **Q25 消化器:** 協会公式の正答は(3)。ただし肢(2)「無機塩及びビタミン類は、酵素による分解を受けないでそのまま吸収」の断定には注意が要る。厚労省「日本人の食事摂取基準（2020年版）」の[ビタミンB6章 PDF14頁・印刷222頁](https://www.mhlw.go.jp/content/10904750/000586563.pdf#page=14)は、PLP/PMPが消化管内のホスファターゼによって加水分解されてから吸収されると記す。試験上の三大栄養素との対比を説明できても「ビタミン類すべてそのまま」を一般事実として教えることはできない。公式正答は変えず、この肢の表現を一次資料で整合できるまで構造化解説を保留。
- **Q29 体温調節:** 厚労省「職場における熱中症予防対策マニュアル」PDF9～10頁（印刷4～5頁）は、視床下部の体温調節中枢、恒常性、暑熱時の皮膚血流と発汗を説明する。厚労省の甲状腺情報はホルモン過剰による代謝・体温上昇を示す。寒冷時の皮膚血管収縮と「内臓血流増加ではない」の根拠を肢別に再照合し、候補文を修正して独立レビューへ戻す。
