# 2025年10月 2級土木施工管理・第一次検定（土木）原典マップ

全国建設研修センターの[試験問題・正答一覧](https://www.jctc.jp/mondai/)にある「令和7年度 2級土木施工管理技術検定 第一次検定（土木）」を対象にする。問題・正答のURL、SHA-256、PDF頁、土木の公式正答No.1〜66を `source-map.json` に固定した。正答PDFには鋼構造物塗装と薬液注入の表もあるため、先頭の「種別：土木」表だけを採用する。

再生成: `py -3.12 scripts/civil2-2025-extract-source.py QUESTION.pdf ANSWER.pdf`。PDFは公開URLから取得し、ハッシュが一致しなければ停止する。問題本文はルビの分離や図・数式を含むため、テキスト抽出だけでは公開しない。

`q01-draft.json` は原頁・正答表を目視照合した未公開の文字起こし。原図は `q01-figure.png` に切り出した。図を必要としないNo.6〜10は問題頁6〜7と正答表を目視照合し、四肢の理由を実Opus 5.5で指摘修正後、5/5 PASSとして演習データへ接続した。No.11〜16も問題頁7〜8と正答表を目視照合し、全24肢を実Opus 5.5で再審査して6/6 PASSとした。No.12の高強度コンクリートの強度範囲は[国土交通省の資料](https://www.mlit.go.jp/maritime/content/001598467.pdf)のPDF 53頁でも裏付けた。No.17〜20は問題頁9と正答表を目視照合し、全16肢を実Opus 5.5で再審査して4/4 PASSとした。No.21〜24は問題頁10と正答表を目視照合し、全16肢を実Opus 5.5で再審査して4/4 PASSとした。No.21・22・24の解説は国土交通省の護岸・砂防・路盤資料でも確認した。生のモデル応答・実際に解決されたモデル名・原典ハッシュ・候補データハッシュは各バッチのrelease-receiptに残す。現時点の2025年版は**19/66問**であり、残り47問は未公開。正答番号は原表からマップ化したが、今後公開する各問ごとに本文・選択肢・図・正答・解説を改めて照合する。2026年度と異なる試験回（2025年10月）として表示する。
