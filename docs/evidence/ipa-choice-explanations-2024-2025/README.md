# IPA直近2年・全肢解説

対象はIPA高度9区分の2024・2025年、合計1,100問。各問題の全選択肢について、正答理由と誤答理由を個別に保持する。

## 完了条件

- 1,100問すべてで、画面に出る肢と `choiceExplanations` のキーが完全一致する。
- 各理由は55字以上で、公式正答に応じて「正しいです。」「誤りです。」が一致する。
- 初回執筆と独立査読を別Claudeセッションで行う。
- 査読時の問題・選択肢・公式正答と、査読後overlayのSHA-256を `review-ledger.json` に固定する。
- 査読で見つけた誤りは同じURLで使うoverlayを修正し、修正後hashを台帳へ記録する。
- 全件査読、型検査、質問データ検査、関連UIテストが通るまで公開ブランチへ統合しない。

## 2026-09-23時点

- 初回執筆: 1,100/1,100
- 独立査読: 台帳の件数を正本とする。Claudeの5時間枠回復後に未査読分を自動再開する。
- UI: 誤答時は利用者が選んだ肢の理由を先頭に表示し、全肢の理由も続けて確認できる。

生成・査読の生ログはローカル `logs/ipa-choice-explanations-*` に保存し、リポジトリには問題・正答・解説のhash台帳だけを残す。
