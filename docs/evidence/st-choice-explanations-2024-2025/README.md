- 2024年度 午前I 30問、午前II 25問

各選択肢には正答理由または誤答理由を収録し、午前Iと午前IIを別の問題紙として扱う。2024年度の図表問題9問は、IPA公式問題PDFから問題に必要な図表だけを切り出して表示する。

- 2024年度 午前II 問題・解答

- 2025年度 午前II 問題・解答

## Opus 5.5レビューゲート

全110問を `claude-opus-5-5`、`firstParty` でレビューした。`review-receipts.json` には、質問入力ハッシュ、候補解説ハッシュ、採用ハッシュ、公式資料ハッシュ、requested/canonical model、provider、modelUsage、prompt/raw hash、指摘一覧を保存する。

採用条件は次の全てを満たす場合に限る。

- 判定が `PASS`
- 指摘が0件
- requested/canonical modelが `claude-opus-5-5`
- providerが `firstParty`
- modelUsageのcanonical model/providerも一致
- 質問・選択肢・正答・既存解説・図表情報の入力ハッシュが現行データと一致
- 候補解説ハッシュと採用ハッシュが現行候補に一致
- 公式資料ハッシュが一致
- 1バッチに午前Iと午前IIを混在させない

最終結果は110問採用、保留0問、440選択肢収録である。入力の単一項目変更、旧形式ハッシュ、`FIX`、指摘あり、候補差し替え、採用ハッシュ不一致、モデル・provider不一致を拒否する回帰テストを追加した。
