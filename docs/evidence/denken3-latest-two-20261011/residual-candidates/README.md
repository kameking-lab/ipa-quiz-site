対象は2026年度上期法規Q10と2025年度下期電力Q1の2原問です。保存済み原稿を再利用し、計10肢の候補をここへ保存します。公式原問のQ10物理16頁・Q1物理4頁を画像と文字で照合し、公式正答表からQ10=2、Q1=3を独立抽出しました。

Q10の肢2にあった、定期点検を月次・年次の区分で説明する未裏付けの追加文を除き、日常点検と定期点検の取り違えに説明を限定しました。JEMAの2007年版と機器別の点検周期は補助情報として保存しましたが、JEAC 8011-2025の代用にはしていません。適用版本文、精密点検の周期を含む定義、保守の直接定義が未取得です。

両候補は本番loader、registry、native一覧、sitemapに接続していません。`sourceReady=false`、`wholeQuestionGO=false`のままで、追加登録0、全肢完成の追加0です。PR725の収録131/132原問、全肢完成130/132原問という集計は変えません。資料の版と不足を区別しており、新しいstrict Opus/firstParty receiptや掲載許諾を得たとの主張はしません。
