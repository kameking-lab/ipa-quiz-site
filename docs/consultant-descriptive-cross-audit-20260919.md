# 労働安全コンサルタント記述式解説 クロス監査（2026-09-19）

## 監査範囲と結論

- 対象は `consultant-2021-descriptive.json` 28問と `consultant-2022-2023-descriptive.json` 56問、計84問。
- 各問を対応する `papers/cskohyo-*.json`、`presentation/cskohyo-*.json`、presentation の図表切出し、paper のページ画像と突合した。
- 全84問について、設問・小問の回答有無、指定個数、式、数値、単位、図表の読取り、法令・指針の時点、非公式解答である旨、参照URLを確認した。
- 構造上の欠落、孤児ID、欠損画像、空解説はなかった。全84問に「公式解答ではない」旨の明示がある。
- 内容面では **Critical 2件、High 2件、Medium 3件、Low 5件**を検出した。特に健康情報の区分と並列系MTTF_Dは、答案の結論そのものが変わるため公開前修正が必要である。

重大度は、`Critical`＝正答の主要部分が複数誤り、`High`＝法令・主要数値・結論の誤り、`Medium`＝一部小問・図表読取り・適用範囲に実質的な誤りまたは曖昧さ、`Low`＝表現・指定形式・過度な一般化、とした。
