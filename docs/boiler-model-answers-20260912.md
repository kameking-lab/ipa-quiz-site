# 特級ボイラー・記述式の表示修正（2026-09-12）

## 問題と修正

特級ボイラーは各年度24問が全て記述式として取り込まれていた。そのうち問4・5・10・11・16・17・22・23は、原本上では5択の組合せ問題である。2年度16問を択一として登録し直した。原文textは変更せず、表示用presentationの末尾から5選択肢を分離した。

公式の正答・正答例ページを画像で確認し、以下の正答を登録した（順は上記8問）。

- 2026年4月掲載：5, 3, 5, 3, 3, 4, 3, 2。公式PDF34・36・39・41ページ。
- 2025年4月掲載：1, 1, 4, 2, 5, 3, 1, 4。公式PDF32・35・38・40ページ。

原本：
- https://www.exam.or.jp/wp-content/uploads/2026/04/LC20260401-2.pdf
- https://www.exam.or.jp/wp-content/uploads/2025/04/LC20251101.pdf

空欄枠に接した指示文が文字起こしから脱落していた問3・9・15（両年度）と2026問21を復元した。空欄枠を［　］と表記し、意図的な誤肢の数式は変更していない。再生成で失われないようpresentation-overridesにも反映した。

全記述式の「確認済みにする」を「模範解答を見る」に変更し、メモ入力なしでも解答を開けると説明した。模範解答は自動採点せず、既存の進捗・メモ保持を維持する。表示本文は各設問への具体的な解答と理由であり、公式PDFへのリンクだけではない。

特級32記述等の既存解答は小問・空欄への数値、語句、計算過程を含むことを通読確認した。公式正答例を参照したサイト独自の整理と明示し、各問の公式正答例ページへ直接リンクする。2026問2は作図を問うため、公式正答例から流れ方向と温度分布の図を2枚掲載した。計算の途中丸めによる公式例と計算値の差は区別したまま保持する。

コンサルタント記述56問は年度別に全小問との照合を実施し、2024年度5問と2025年度6問を補訂した。対数計算の中間丸め、反力方向、許容たわみ、騒音補正条件、局所排気計算表の全欄、反応式の係数、クレーン・足場の条件などを明確化した。局所排気フード等の4模式図と熱交換器の温度分布図も独自に作成して掲載。独自模範解答を公式解答と称しない。

安全問題の総数1972問は変わらず、公式採点1524問、公式正答未公表360問、記述・複数選択等88問となる。最後の分類には二つの記号を答える問題8問を含み、自動採点しない。
