# 2021年度（第49回）労働安全・労働衛生コンサルタント試験 問題PDF出典監査

監査日: 2026-09-19 JST
対象: 令和3年度（第49回）、全11科目
範囲: 出典の特定と原本同一性の確認のみ。取り込み・問題データ生成・既存カタログ変更は行わない。

## 結論

- 11科目すべてについて、旧公式索引上のファイル名と旧公式URLを確定できた。
- 旧公式PDF本体は現行サイトから取得できず、Wayback Machineでも公式PDF本体の保存物を確認できなかった。そのため、無認証で公開されている `osh-lab.com` のPDFコピーを復元元候補とした。
- 11ファイルすべてが、旧公式索引の科目・ファイル名、表紙の試験回・試験名・科目、2022年度公式PDFと同じ版面規則、公式公表版特有の正答丸印、PDF生成メタデータのまとまりに整合する。
- 11ファイル中10ファイルは、2024年にWayback Machineへ保存された `osh-lab.com` のPDFともSHA-256が完全一致した。土木安全だけは同サイトのWayback保存物を確認できなかったが、現行PDF、WordPress公開メタデータ、旧公式索引、表紙・版面・生成メタデータは整合する。
- 復元元候補としては全11件を採用可能と判断する。ただし、公式配布時のSHA-256を示す一次記録は存在しないため、「公式サーバー上のファイルとバイト単位で同一」とまでは証明できない。取り込み時は本書記載のSHA-256で固定し、`sourceMode` を「旧公式索引で同定した公開コピー」など、現行公式PDFと区別できる値にするのが安全である。

## 公式旧URLの確定方法

旧公式ページ `https://www.exam.or.jp/exmn/CSkohyo.htm` は、`exmn/csv/cspdf.csv` を読み込み、JavaScriptでPDFリンクを組み立てていた。

1. [Wayback保存の公式CSV（2022-05-28）](https://web.archive.org/web/20220528065047id_/https://www.exam.or.jp/exmn/csv/cspdf.csv) は、先頭列に「令和3年10月19日」、各科目行に `CS_r031` と `CS20211901`～`CS20211911` を掲載している。
2. [Wayback保存の公式リンク生成コード（2021-11-05）](https://web.archive.org/web/20211105100047id_/https://www.exam.or.jp/exmn/default.js) は、CSVのディレクトリ名とファイル名を `../<directory>/<basename>.pdf` として結合する。
3. したがって旧公式URLは `https://www.exam.or.jp/CS_r031/CS20211901.pdf`～`CS20211911.pdf` であり、推測ではない。
4. CSVのSHA-256は `16ea10d9294263521dc8500e1cb80b7fde7128a918cbca5c6831773cf7a40752`、リンク生成コードのSHA-256は `7bef3ad426d68da1d9a0a9a71e76b8c61b4729203aad6df7c1ec98f67d7c9991` だった。

[厚生労働省の筆記試験合格者発表](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000094015_00010.html) も、第49回（令和3年度）の両試験を2021年10月19日に実施したと明記している。PDFの表紙自体には、11ファイルとも実施日の印字はない。以下の「日付」は、表紙では「記載なし」、旧公式索引と厚生労働省発表では「令和3年10月19日」である。

2026-09-19時点で旧公式URLをGETすると現行トップページへ転送され、PDFは返らない。また、`2022-12-31` を基準にしたWaybackのnearest playbackは11件とも404だった。少なくとも `CS20211901.pdf` のCDX完全一致検索も空だった。このため、旧URLは由来確認用であり、取り込み元URLには使えない。

## 原本同一性の根拠

### 1. 科目とファイルIDが旧公式索引に完全一致

公式CSVは、01から11まで欠番なく、上表と同じ順序で科目を対応付けている。公開コピーのランダムなURL名からIDを推測したのではなく、各PDFの表紙科目を公式CSVのIDへ突き合わせた。

`osh-lab.com` の公開WordPress APIも、各添付を `R3産業安全一般`、`R3機械安全`、`R3労働衛生工学` などの名称で2022-06-11に登録している。APIの各添付IDは、01から順に `5604, 5605, 5602, 5606, 5601, 5607, 5603, 5613, 5614, 5612, 5611` である。例: [産業安全一般の添付メタデータ](https://osh-lab.com/wp-json/wp/v2/media/5604)、[労働衛生工学の添付メタデータ](https://osh-lab.com/wp-json/wp/v2/media/5611)。

### 2. PDFが一つの公式生成バッチとして整合

11ファイルはすべてPDF 1.4、Producerは「一太郎」。労働安全7科目のAuthorは `Siken11`、労働衛生4科目のAuthorは `Siken13` でまとまり、作成・更新日時はすべて試験3日後の2021-10-22である。作成時刻は安全科目が09:23～14:18、衛生科目が14:24～14:26に連続する。公開コピーサイトで再PDF化した痕跡ではなく、試験協会側の公表用生成バッチと考えるのが自然である。

## 公開性と利用時の表記

復元元PDFは、ログイン、購入、CAPTCHA回避、アクセス制御回避を必要とせず、通常の公開URLから取得できる。試験問題が元来協会の「公表試験問題」として公開されたことは、旧公式CSVと現行の[協会公表問題ページ](https://www.exam.or.jp/cskohyo/)で確認できる。

ただし、本監査は公開経路と原本同一性を評価したもので、ミラー運営者の著作権許諾を法的に保証するものではない。データ取り込み時の出典表記は、次の二段構えにする。

- 原典: 公益財団法人安全衛生技術試験協会、第49回（令和3年度）労働安全・労働衛生コンサルタント試験、2021-10-19実施。
- 復元元: 上表の `osh-lab.com` 公開PDFコピー。旧公式URLも監査情報として保持するが、利用者向けリンクには現在取得可能な復元元URL又は自前で固定した監査済みコピーを使う。

問題解説の根拠URLを政府一次資料に限定する既存ルールは、解説内容の法令・統計根拠に対する制約である。本件の問題原本復元元はそれと分け、上記のとおり明記する。

## 取り込み前の推奨チェック

1. ダウンロード時に本書のSHA-256と全11件一致することを必須にする。
2. `CS20211901`～`CS20211911` の公式ID、科目名、旧公式URL、復元元URLを別フィールドで保持する。
3. 択一4科目は正答丸印数が30 / 15 / 30 / 15、記述7科目は正答なしであることを自動検証する。
4. 全PDFの末尾まで抽出し、「（終り）」とページ数を確認する。冊子の印字ページ数ではなくPDF実ページ数を使用する。
5. 土木安全はWayback上の同一バイト列が未確認なので、別公開アーカイブが見つかった時点でSHA照合を追記する。

## 監査の限界

- 公式PDF本体のWayback保存物、公式SHA-256、公式Content-Lengthの同時代記録は見つからなかった。
- したがって、上表のSHA-256は「取得した公開コピー」を固定する値であり、「公式サーバー上の当時のバイト列」を直接計測した値ではない。
- 10件のWayback一致は、少なくとも2024年から2026-09-19まで公開コピーが同一バイト列で維持されたことを示す。2021年の公式配布時点まで遡る直接証拠ではない。
- それでも、公式旧索引によるID確定、表紙・科目・問題構成、正答丸印、2021-10-22の一括生成メタデータ、2022年度公式PDFとの版面一致、別サイトの問題再掲との照合が相互に独立して整合するため、原本コピーとしての実務上の信頼度は高い。
