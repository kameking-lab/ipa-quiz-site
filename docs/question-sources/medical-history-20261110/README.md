# 医療3区分の過年度部分収録（2026-11-10）

看護師・保健師・助産師の2023・2022・2021年度に、午前の確認済み原問を各10問ずつ追加した。合計90問・360肢。各年度の全問収録ではない。年度は既存データと同じ年度表記で、実施年はそれぞれ2024・2023・2022年となる。

## 公式出典

- 2023年度：[第110回保健師・第107回助産師・第113回看護師](https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/topics/tp240424-03_04_05.html)
- 2022年度：[第109回保健師・第106回助産師・第112回看護師](https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/topics/tp230524-03_04_05.html)
- 2021年度：[第108回保健師・第105回助産師・第111回看護師](https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/topics/tp220421-03_04_05.html)

各年のJSONには問題・正答PDFのURL、取得した原本のSHA-256、照合済み原文・選択肢・公式正答・原本ページを保存している。問題データの `sourcePdfUrl` は該当ページ、`sourceAnswerUrl` は公式正答値表を指す。正答は解答速報・非公式解答から作成していない。

## 取り込み・確認

1. 公開ページがリンクする公式PDFだけを、取得間隔を空けて保存した。
2. テキストを抽出した。欠落する数字・文字化け・英語ルビの混入があったため、採用した設問の原本ページを画像化して照合し、欠落を修復した。
3. 原本の問題番号・選択肢順序を保ち、公式正答の番号を内部のア～エへ対応させた。正答セルの座標からの読み取りでも90問を再照合した。
4. 解説と全肢の理由は独自作成した。統計の更新や法改正に合わせて原問・正答を変更することはしていない。数値はその原問で問われた値として説明している。
5. 図・表の画像が必要な問題は、この追加には採用していない。既存の原図を持つ問題と、既存の採点除外・公開保留の扱いは維持した。
6. 既存8個の問題JSONは作業開始時点のコミット `630b02b25` とバイト単位で同一である。

補助スクリプト・取得PDF・レンダリング画像は実行フォルダの `tools/k10a-impl/` に保存する。リポジトリには原本PDFや一時スクリプトを追加していない。

## 未収録

この追加に含めていない原問は未確認として扱う。図表の切り出し・原文転記・全肢の説明根拠の確認を終えるまでは追加しない。公式PDFは取得できているため、「公式が非公開」を未追加理由にしていない。

第111回看護師午前問6の正答値表には2と3が記載されている。この追加には含めず、単答として片方だけを登録していない。既存問題の公式正答も変更していない。

## 利用条件・社長確認対象

既存と同じ `MHLW-attributed` を用い、厚生労働省の出典、表示上の加工、独自解説であることを明記した。

[現行利用条件](https://www.mhlw.go.jp/chosakuken/)では、特記・権利表記がない情報はPDL1.0に準拠し、出典と加工の明記を求めている。[適用除外の別紙](https://www.mhlw.go.jp/chosakuken/exhibit.html)も確認した。各試験の個別転載許諾を取得した記録は本作業にはなく、第三者権利を含む素材の再利用可否も包括的には確認していない。許諾が必要かどうかの最終判断は社長の確認対象とし、取得済みと表現しない。対象となる9問題PDFと実施団体は各年度JSONおよびレーンレポートに列挙する。
