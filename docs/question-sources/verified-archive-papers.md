# 公式PDF保存版の出典台帳

`verified-archive-papers.json` は、公開問題を出典として照合した記録です。資格コード、年、回、科目、表紙・正答表の試験識別情報を冊子ごとに記録します。問題・正答ともに元URLと実際に検証したPDFのバイト列のSHA-256を持ち、保存版には日時固定URLを記録します。

保存版の取得では、Internet Archiveの保存日時と元URLをレスポンスで照合しました。試験記号がある冊子は問題と正答の記号、科目別の正答表は冊子の科目名と表の列を合わせています。正答欄の番号を演習用の選択肢キーへ換算し、原稿に含まれる全問を比較した後で、図版・解説等の公開要件を判定しました。共通の問題冊子が複数の原稿に含まれる公害防止管理者は、冊子に記載された科目の公開ページへ収録しています。

`questions` には問題ID、掲載時の番号、正答表上の設問番号と照合した正答を記録します。無線従事者のB問題は空欄別の公式正答を `nativeAnswers` に、全員正解の設問は公式の採点指定を `scoring` に記録します。試験回や正答を照合できない冊子、既存・候補間の重複、表示できない図版や公開品質の要件を満たさない問題は、この台帳に含めません。

調理師試験センターの令和4年度分は、調理技術技能センターに試験を委任した岐阜県が公開した問題とセンター名義の正答です。[岐阜県の委任案内](https://www.pref.gifu.lg.jp/page/1636.html)・[令和4年度正答](https://www.pref.gifu.lg.jp/uploaded/attachment/425081.pdf)

奈良県実施分は令和6年度の県の冊子と正答を収録しています。令和7年度以降は関西広域連合が実施します。[奈良県の実施団体変更案内](https://www.pref.nara.lg.jp/n086/9705.html)
