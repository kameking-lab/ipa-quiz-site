# PLAN10-D04 国家公務員採用試験の補充候補

2026年11月20日確認。対象は全国実施の国家公務員採用試験で、試験実施年度の2022～2026年度を調べる。優先順位は[人事院の2026年度実施状況](https://www.jinji.go.jp/content/000016039.pdf)の第1次受験者数を基準とし、各試験は新しい年度から着手する。

人事院の[試験問題例一覧](https://www.jinji.go.jp/saiyo/siken/mondairei/mondairei_top.html)から問題冊子を取得する。[正答番号の公表ページ](https://www.jinji.go.jp/saiyo/seitou.html)は掲載期間終了後の表示だったが、一般職・専門職の多肢選択式の公開冊子には、末尾に正答番号表が付くものがある。PDFの表紙・正答表で年度、試験区分、問題番号を照合する。正答を確認できない記述・論文、公開版で本文が欠けた問題、原図表を再現できない問題は収録対象から外す。

## 重複照合

- 依頼の収録済み一覧にある試験は、補充分の登録と年度・区分を照合する。一般職大卒の2026・2025年度基礎能力、総合職大卒の2026・2025年度基礎能力、総合職院卒の2026年度基礎能力、国税専門官の2026年度A・B、2025年度A、2024年度A・Bの専門は照合対象。 [収録データ](https://github.com/kameking-lab/ipa-quiz-site/tree/release/kako-20261120/data/questions)
- 労働基準監督官の2026・2025年度基礎能力、航空管制官の2026年度基礎能力、入国警備官の2025年度基礎能力、航空保安大学校学生の2025年度も照合対象。人事院が複数試験に同じ基礎能力冊子を使っている場合は紙面上の問題番号を比較して重複を除く。
- C19の東京都・大阪府の教員採用、裁判所事務官は対象外。C19の候補一覧にある一般職高卒・税務職員の記述は調査結果で、同ブランチに対応する問題データはない。 [C19候補一覧](https://github.com/kameking-lab/ipa-quiz-site/blob/9572bab493e94ff37db833fd3b5fca7fd1e72aa9/docs/plan9/c19-candidates.md)
