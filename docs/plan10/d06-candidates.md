# PLAN10-D06 登録販売者試験の収録候補

対象年度は令和8年度から令和4年度まで（2026〜2022年度）。同じ年度は受験者数の多い実施区分を優先する。受験者数は厚生労働省の令和7年度実施状況に基づく延べ人数。[令和7年度登録販売者試験実施状況](https://www.mhlw.go.jp/content/001738114.pdf)

`main` の `tohan` には関西広域連合の令和7年度・令和6年度（各120問）が収録済み。手元補充分の公開候補スナップショット（`origin/cx/kako-cloud-base-20261119` の `de42ac198`）には、関西広域連合と東京都の令和4〜8年度が登録されているため、両区分を対象外とする。C19 の差分は教員採用・裁判所事務官だった。

同一問題を複数の実施機関が公表している場合は、本文・選択肢・正答の同一性を照合して代表原本を使う。愛知県・静岡県・岐阜県・石川県の令和8年度は共通問題として1回分を収録した。千葉県・神奈川県の令和8年度は東京都と共通のため対象外。埼玉県の令和8年度は正答が東京都と同一で、問題原本を照合して収録の要否を判定する。福岡県の令和8年度試験は12月20日実施予定。沖縄県の令和8年度は確認時点で公式問題・正答の掲載を確認できなかった。[福岡県の令和8年度試験案内](https://www.pref.fukuoka.lg.jp/contents/r08tourokuhanbaisyashiken.html)

解説には各年度の試験問題作成時点の手引きを用いる。[厚生労働省の手引き](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000082537.html)
