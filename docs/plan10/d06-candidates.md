# PLAN10-D06 登録販売者試験の収録候補

対象年度は令和8年度から令和4年度まで（2026〜2022年度）。同じ年度は受験者数の多い実施区分を優先する。受験者数は厚生労働省の令和7年度実施状況に基づく延べ人数。[令和7年度登録販売者試験実施状況](https://www.mhlw.go.jp/content/001738114.pdf)

`main` の `tohan` には関西広域連合の令和7年度・令和6年度（各120問）が収録済み。手元収録済み資格一覧も同じ `tohan` を示している。C19 の差分は教員採用・裁判所事務官で、登録販売者の問題データとの差分はない。

同一問題を複数の実施機関が公表している場合は、本文・選択肢・正答の同一性を照合して代表原本を使う。千葉県・埼玉県は問題と正答の両方を取得できた回が収録対象。福岡県・沖縄県の令和8年度は確認時点で公式問題・正答の掲載を確認できなかった。

解説には各年度の試験問題作成時点の手引きを用いる。[厚生労働省の手引き](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000082537.html)
