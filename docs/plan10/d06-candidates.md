# PLAN10-D06 登録販売者試験の収録候補

対象年度は令和8年度から令和4年度まで（2026〜2022年度）。同じ年度は受験者数の多い実施区分を優先する。受験者数は厚生労働省の令和7年度実施状況に基づく延べ人数。[令和7年度登録販売者試験実施状況](https://www.mhlw.go.jp/content/001738114.pdf)

`main` の `tohan` には関西広域連合の令和7年度・令和6年度（各120問）が収録済み。手元補充分の公開候補スナップショット（`origin/cx/kako-cloud-base-20261119` の `de42ac198`）には、関西広域連合と東京都の令和4〜8年度が登録されているため、両区分を対象外とする。C19 の差分は教員採用・裁判所事務官だった。
