# PLAN10-D02 公立学校教員採用試験の収録候補

中部・近畿の対象21教育委員会。対象は2022～2026年度実施（令和4～8年度実施、原則として令和5～9年度採用）。データの年度と採用年度は区別する。東京都・大阪府・裁判所事務官は C19 の担当分と突合済み。

受験者数は文部科学省「令和7年度（令和6年度実施）公立学校教員採用選考試験の実施状況等」の第2表（採用区分別競争率）による。受験者数が多い自治体から確認し、問題と正答が揃う一次の共通教養、小学校、その他校種・教科の順で収録候補とする。各区分では新しい実施年度から確認する。[文部科学省の集計表](https://gkz781swok1ivzu2.www.mext.go.jp/content/20261001-kyoikushokuin-000046447_2.pdf)
