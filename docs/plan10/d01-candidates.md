# PLAN10-D01 公立学校教員採用試験の候補

2026年11月20日確認。対象は2022〜2026年度実施（令和5〜9年度採用）の一般教養、教職教養、教科専門の択一式。受験者数は比較できる2024年度実施の通年集計で、共同で出題する自治体は同一の問題を一度だけ収録する。依頼の収録済み一覧と `origin/cx/kako-cloud-c19-20261119` の東京都・大阪府教員採用および裁判所事務官の追加を照合した。 [文部科学省の集計・第2表-1](https://www.mext.go.jp/content/20261001-kyoikushokuin-000046447_2.pdf)
