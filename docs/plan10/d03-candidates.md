# PLAN10-D03 公立学校教員採用試験の候補

2026年11月20日確認。年度は試験実施年度（原則として翌年度採用）。2026年度から2022年度までを対象とする。優先順は文部科学省の2025年度採用分の受験者数（第2表-1、通年）。校種共通の教職・一般教養と、受験者の多い小学校・中学校などの専門を優先する。広島県と広島市の合同試験は1件として扱う。 [受験者数の出典](https://www.mext.go.jp/content/20261001-kyoikushokuin-000046447_2.pdf)
