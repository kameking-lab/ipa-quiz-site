# 資格別の学習人数

表示: 「今◯人が〇〇を学んでいます。」を人数の降順、同数は資格コードの安定順で並べ、末尾を「一緒に頑張りましょう！」にする。表示名は公開資格台帳・既存日本語名・安全衛生hubから取得し、衛生管理者のhub別名は既存資格コードに統一する。

## 計測の定義

- 「今」は、可視タブに表示された問題で直近2分以内に操作したブラウザ。初回表示・資格切替も活動として扱い、30秒間隔で更新する。
- トップ・資格選択・模試設定・完了画面は取得GETのみで、学習人数に加えない。記述/論文・公開解説・技能問題を読む画面も、その実際の問題資格を計測する。目標資格やURLの推測値からは補完しない。
- 同じブラウザのタブは既存の日次UUIDを共有し、DB上の既存hash主キー1行で最後に活動した資格へ所属する。資格数をまたいだ二重加算はしない。人・端末の厳密な同一性は判定しない。
- Web LocksでID生成・ローテーション・送信を直列化する。日替わり時だけ旧IDを既存localStorageキーへ一時保存し、同じDBトランザクションで旧hash行を削除する。成功後に一時保存を消す。ロック未対応ブラウザでは既存の当日IDを再利用するだけで、新規IDの生成・切替はせず集計GETを行う。
- 離脱・非表示・無操作後は活動時刻を更新しない。最後の活動から最大2分残り、期限境界で集計対象から除外、次回取得/記録で期限切れ行を削除する。
- 既知bot UA・WebDriverを除外する。ローカル、テスト、Vercel preview/developmentは記録しない。UAで偽装botを完全に判別する仕組みではない。E2E表示データは明示したsynthetic fixtureで、本番へ記録しない。

## データと失敗

既存StudyPresenceにnullable exam列1つを追加する。氏名・ログインID・IP・解答・問題ID・科目・行動履歴を追加保存/公開しない。旧行の資格は推測せずnullのまま期限切れまで残す。APIが返すのは公開資格IDと人数の配列・合計だけ。

計測失敗・DB未設定・未適用migrationは503とcount/exams=null。表示は非表示で、0への置換はしない。真の0だけ空配列で自然な空表示を出す。数値更新はstable keyで、aria-live=off、長い一覧は112pxのスクロール領域に収める。

## リリース前提

主担当の既存DB運用で20261011060000_study_presence_examを先に適用し、アプリを公開する。専任担当はmigration適用・main merge・deployをしない。未適用中は資格別計測を非表示にする。既存ページを開いた旧クライアントの資格なしPOSTは加算せず400とし、旧行は期限切れになる。

局所テストはAPI、表示、2分の境界、同ブラウザ再利用、資格切替、日替わり、ロック待機、失敗/0、bot/テスト除外を対象にする。実SQLの重複・旧ID削除・期限切れは本番DBを使わずローカルPGliteで確認した。人数のfixtureは実利用者数を表さない。
