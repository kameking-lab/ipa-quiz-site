# 自習室の背景・家具つきチワワ v3

ar-4（2026-11-17）の素材。保存先は実行フォルダ内の `research/study-room-art-20261117/v3/`。
アプリへの組み込みはこの作業には含めない。

## 方針

- 背景5段階（小部屋・教室・広い教室・大教室・図書館ホール）には机・椅子を描かない。
- 本棚・アーチ窓・木材・セージ色・真鍮・木もれびは ar-2 のA案を引き継ぐ。
- チワワ・家具・勉強道具を一体の透過素材にする。椅子と体、前足と天板の重なりは生成画像内で完結させる。
- 基本20種（勉強12、うとうと4、遊ぶ／寝る4）。横向きと斜め向きは別に生成し、左右反転を併用する。
- 人数は画像枚数ではなく犬の実数で数える。教え合い・じゃれ合いは各2人。
- 服の調整に使う体の基準点は各素材の座標として保持する。既存の服を含む画像全体を重ねない。

## 引き継ぎ先

`backgrounds/` に背景、`sprites/` に透過素材、`originals/` に生成原画を保存する。
`floors.json` は完成画像に合わせた床の遠近基準と設置可能範囲であり、席の固定座標ではない。
`assets.json` は切り抜き・余白・反転・寸法、`prompts.json` は生成プロンプトを保持する。

補助処理は `tools/ar-4/`、結果レポートは `reports/ar-4.md`（いずれも実行フォルダ内）。
生成には built-in image_gen を使用する。Pythonは切り抜き・反転・縮小・合成・検証に使用し、犬や家具の描画には使用しない。

## 完成した素材

- 背景5枚（PNGとWebP、各1024×1536）。机・椅子は描かれていない。
- 勉強12種、うとうと4種、遊ぶ／寝る4種。横向きと斜め向きの原画40枚から、左右の反転を含む透過PNG80枚・透過WebP80枚を保存。
- `body-anchors.json` に80素材・88匹の首・肩・胸・腰・胴の角度・頭幅。座標は加工後素材のピクセル値。胴の参考多角形は服の完成マスクではない。
- `anatomy-review.json` に40原画・44匹の足4・尾1・耳2・目2の目視点検と、机・体毛などによる自然な隠れの記録。反転版40枚は原画との画素一致を確認。
- `overview.png` に全体、`samples-overview.png` に5・12・24人の見本、`samples/` に原寸と390px幅の各3枚。
