# 一次資料確認の引継ぎ

対象は 2025 年労災問 8（公式正答 C）と 2026 年労基・安衛問 7（公式正答 E）。両問とも全肢の一次根拠が閉じていないため HOLD を維持し、完成問増分は 0 問です。

- `EVIDENCE-DELTA.json`: 出典 URL、基準日・版、原本 SHA-256、該当箇所、全肢の確認状況、残る原文未確認箇所。
- `OFFICIAL-LITERAL-QA.json`: 公式択一 PDF と保存原稿の問題文・全選択肢一致、公式正答表の視認照合。原問・正答の改変はありません。
- `HOLD-LOCAL-PATCH.json`: 2025 年労災問 8 の private HOLD metadata のみの局所補正案。根拠がない「法 12 条 3 項の一括有期事業を含む括弧書き」の探索前提を除去し、解消済み 2 項目を残存から除く案。完成稿扱いにはしません。
- `COLLECTION-ASOF-20250411-EXCERPTS.json` / `LABOR-ACT-ASOF-20260410-EXCERPTS.json`: 基準日 e-Gov 原本の本則だけから抽出した条文。附則内の同じ番号の改正規定と混同しません。
- `*-receipt.json`、公式 HTML / PDF、該当ページ PNG: 取得証跡と視認資料。

新たに閉じた箇所は、労災問 8 の B（所轄所在地と提出先）・E（請負金額定義による損料加算の一括要件への接続）、労基問 7 のイ（派遣元の人数と就業規則義務）・エ（事業場ごとの意見書）です。

労災問 8 の C/D は行政解釈原文が未確認。A の制度区別は条文で裏付けできますが、直接の公式説明原本は未取得です。労基問 7 のアは法定の意見聴取・添付要件と、労働契約法施行通達からの推論を直接の通達確認と区別しています。ウは休暇としての記載事項まで確認、法への参照だけで足りる部分は未確認。オは減給制裁の意思表示到達日を算定事由発生日とする通達原文が未取得です。

厚労省公式法令データベースで関連語・通達番号を検索し、関連する公開通達を取得しました。検索に出なかったことを原文の不存在とは扱っていません。育児のみの旧通達を介護にも適用する根拠に流用していません。URL 数字から東京労働局 PDF の発行日を推定していません。

`python build_evidence_delta.py` は取得原本・保存原稿・公式問題・公式正答の hash と照合結果を検査し、引継ぎ JSON を再生成します。ランタイム、既存原稿、所有者ロックには変更していません。新 API、外部モデル送信、公開、PR 作成はありません。
