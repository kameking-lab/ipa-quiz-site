# 雇用保険3原問の追加一次資料調査（2026-10-11）

対象は2025年雇用問6（ウ・エ・オ）、問7（A～E）、2026年雇用問1（E）のみ。本文・payload・runtime・lock は変更していない。問2の停止探索も再開していない。

## 新たに確認した一次資料

厚生労働省の旧版公開ページ「雇用保険に関する業務取扱要領（平成25年6月1日以降）」 https://www.mhlw.go.jp/seisakunitsuite/bunya/koyou_roudou/koyou/koyouhoken/data/toriatsukai_youryou.html は、第9～12章と第17～18章への通常公開リンクを持つ。次の2点をブラウザの公開閲覧で確認した。いずれも資料中の該当頁の版記は **(24.4)** または **(25.4)** であり、2025-04-11当日の版を示すものではない。

* 第9～12章、https://www.mhlw.go.jp/seisakunitsuite/bunya/koyou_roudou/koyou/koyouhoken/data/dl/toriatsukai_youryou_i.pdf 、PDF物理74～76頁／印刷244～246頁、52152(2)ハ・ホ。2025問6ウの「就職先賃金の手取額が基本手当額のおおむね100分の100より低い」基準には、任意転居先の労働市場の平均賃金が元住所より低い場合の適用除外がある。手取額は税・社会保険料・労働組合費控除後。エは、法令違反がなくても地域の同種業務の一般水準に比べて賃金以外の労働条件が不当に悪い場合を別に掲げる。オは2か月以上の賃金不払について、近い将来に正当な時期の支払いが確実なら正当理由にならないと記す。
* 第17～18章、https://www.mhlw.go.jp/seisakunitsuite/bunya/koyou_roudou/koyou/koyouhoken/data/dl/toriatsukai_youryou_k.pdf 、PDF物理8～15頁／印刷328～335頁、53251～53302。2025問7 Aについて53302(2)ル末尾は、雇用関係を存続させ賃金を払わない和解でも受給要件を緩和できないと明記する。Bは53254(4)イおよび53301(1)ロ・53302(2)の遡及賃金支払時の取消し・返還に対応する。Cは53253(3)の事業所廃止等による原状回復不能の例外に対応する。Dは53255(5)の二重雇用関係で収入控除がある期間の資格選択に対応する。Eは53251(1)の解雇争議時の条件付き資格喪失確認、53301(1)の暫定的給付に対応する。

この旧版においては問6のウ・エ・オ、問7のA～Eの論点と直接対応する行政記載が実在することまで確認できた。一方、同じ文言・効果が **2025-04-11** にも有効だったことは、この資料単独からは立証できない。既存のR8.4／R8.8資料を旧日に遡及適用もしない。

## 2026年問1E

既存の2013年版20352(2)イは、民間事業主間の一般的な在籍出向・主たる賃金に応じた被保険者資格の扱いを示す。地方公務員法38条1項の兼業許可を得た地方公務員への出向で出向元雇用関係が続くという設問固有の取扱いまでは直接示さない。2026-04-10以前のその直接原典は今回も確認できず、EはHOLDを維持する。

通常の公式PDF取得をローカルPythonで1回試したところ、実行環境の `127.0.0.1:9` プロキシへの接続が拒否された。その後、許可された公開GETで上記2つの厚労省PDFのバイト列を取得・保存し、ハッシュと版記を検証した。取得記録は `source-receipts.json`。国立国会図書館WARPのホームページはブラウザ公開閲覧で403 Forbiddenだったため、こちらは再試行・回避していない。

2013版とR8.4版で重要な9句の空白除去後の文字列が一致することは `comparison.json` に記録した。この一致は両端の観測に限られ、中間の2025-04-11版の存在・同一性の証明ではない。各原問の差分と限定した完成案は `limited-deltas.json`。2026問1Eについては地方公務員法38条の基準日版もe-Govから取得したが、同条は兼業許可の規定であり出向元の雇用保険資格を直接定めない。既存の20352(2)イ～ハも通読し、地方公務員出向を明示しないことを確認した。

2025年の条項番号52152・53302に関する厚労省の改正通知を公開検索で探したが、両条項の中間期間の同一性を証明する公的通知は確認できなかった。e-Govの2025-04-11版労働組合法7条・27条も取得した。問7Eの組合による申立てと、雇用保険の受給資格確認は別の手続であり、設問の「他の要件を満たす限り」を保持して読む必要がある。

次の必要資料は、2025-04-11以前に施行された52152・53251～53302を収める厚労省の版固定原本または通常公開の公式アーカイブ、および2026-04-10以前の20352等に地方公務員法38条兼業許可の出向を明示する行政原典。取得・版確認までは3原問の完成扱い、公開扱いに進めない。
