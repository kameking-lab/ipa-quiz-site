# PLAN9-C20 IT・情報・デジタル・通信の新規資格候補

2026年11月19日確認。依頼の収録済み一覧と `data/questions/` を照合し、実施機関が問題・正答を公開している新規資格を規模順に掲載する。G検定の人数は延べ受験者数。CG-ARTSは検定別に公表している応募者数を規模の目安とし、実施機関の検定区分に合わせて両等級を扱う。
