# 技術士第二次試験 総合技術監理部門 択一式（Ⅰ－1）転記仕様

原本は日本技術士会の公式PDF（スキャン画像）。ページ画像を Read ツールで目視し、**1字ずつ忠実に**転記する。
推測で補わない。読めない字は `〓` を入れ、`uncertain` に記録する。要約・言い換え・誤字の訂正は一切しない（原文に誤植らしきものがあってもそのまま写し、`uncertain` に「原文どおり」と書く）。

## 出力（JSON 1ファイル、UTF-8）

```json
{
  "pass": "A または B",
  "year": "R08 または R07",
  "questions": [
    {
      "number": 1,
      "pages": [1],
      "stem": "問題文（設問文と、(A)～(D)・(ア)～(エ)などの本文・表・注記。選択肢①～⑤の行は含めない）",
      "choiceHeaders": ["A", "B", "C", "D"],
      "choices": ["ア ウ エ イ", "ウ ア イ エ", "イ エ ウ ア", "ア ウ イ エ", "ウ ア エ イ"],
      "hasFigure": false,
      "figureNote": "",
      "uncertain": []
    }
  ]
}
```

- `number`: Ⅰ－1－N の N（整数）。担当範囲の全問を必ず出す。
- `pages`: その問題が載っているページ番号（ファイル名の pNN）。
- `stem`: 設問番号「Ⅰ－1－N」自体は含めない。本文の段落・箇条の区切りは `\n`。紙面の行折り返しでは改行しない。見出し（例「管理特性」）も1行として入れる。
- `choices`: ①～⑤ の5個。丸数字は入れない。
  - 選択肢が表形式（見出し行 A B C D や ア イ ウ エ 等が上にあり、各肢がその列の値を並べる形）のときは、`choiceHeaders` に見出しを左から順に入れ、各肢は列の値を**半角スペース1個**で区切って並べる。見出しが無い通常の文章の選択肢は `choiceHeaders: null`。
  - 選択肢が数値の組などで列見出しがある場合も同様。
- 本文中の表は Markdown の表（`| a | b |` と `| --- | --- |`）で `stem` に入れる。セルの文字も忠実に。
- 図（グラフ・概念図）がある場合は `hasFigure: true` とし、`figureNote` に図の内容（軸・ラベル・値・段の名前など、見えている文字すべて）を書く。図の文字は `stem` には入れない。
- `uncertain`: 判読に迷った箇所を「"語句": 理由」の文字列で列挙。

## 文字の正規化（両パス共通、必ず守る）

- 数字 0-9・ラテン文字 A-Z a-z は**半角**で書く（紙面が全角に見えても半角）。数値内の `,` `.` も半角（例 `1,000` `3.5`）。`%` も半角。
- 丸括弧は**全角** `（` `）`。かぎ括弧「」『』、句読点は紙面どおり（この冊子の読点は多くが全角コンマ `，`、句点は `。`）。中黒 `・`、波ダッシュ `～`、長音 `ー`、全角マイナス/ダッシュ `－` を区別する。
- 選択肢記号 (ア)(イ)… は `（ア）` のように全角括弧＋カタカナ。(A)(B) は `（A）`（中は半角英字）。
- ローマ数字は `Ⅰ` `Ⅱ`。丸数字は紙面どおり（選択肢の頭の①～⑤だけは入れない）。
- 空白: 語の間の空白は入れない（表形式の選択肢の区切りだけ半角スペース）。
- ページ下のフッター（例「R8 21【Ⅰ－1】1/25」）やページ上部の見出し「令和8年度技術士第二次試験問題〔総合技術監理部門〕」「必須科目」、冒頭の「Ⅰ－1 次の40問題を解答せよ…」の注意書きは問題に含めない（ただし冒頭注意書きは year ファイルの別フィールド `preamble` に全文を入れる。Ⅰ－1－1 を担当するパスのみ）。

## 手順

1. 担当範囲の問題があるページを順に Read で開く（ページは `<pagesDir>/<year>_pNN.png`）。範囲外の問題は出力しない。
2. 転記後、各問をもう一度画像と見比べ、数値・否定語（「ない」「誤っている」「不適切」）・「最も」・選択肢の順序を点検する。
3. 指定の出力パスに JSON を Write する。ほかのファイルは作らない。**他パス（passA / passB のもう一方）のファイルは絶対に読まない。**
