# 潜水士・高圧室内作業主任者・発破技士：直近2回監査

確認日：2026-11-03。公式一覧 https://www.exam.or.jp/lckohyo/ を直接確認。
直近2回は令和8年10月掲載と令和8年4月掲載。前者は2026年1～6月、後者は2025年7～12月の実施問題。掲載月を試験実施月として扱わない。
公式一覧には2026年1月1日以降施行の法令に対応していないとの注意書きがある。解説は出題時点の規定として記載し、現行法令の説明とは区別する。

## 実装方式

`eisei1` と同じ `data/questions/<code>/index.ts` と Question データ、同期登録、遅延ロード、試験設定、資格台帳、資格一覧を使用。台帳の `ready-to-ingest` により未公開。既存の公開ルーティングが参照する資格・問題一覧から除外される。4月と10月は `published-april` / `published-october` で区別し、表示も公表月とする。
本文と5選択肢をテキストで保持。正答はPDFの○印から取得。図は必要な設問だけに併用し、`hasImage` と画像URLを付す。各問に問題・正答の同一公式PDF URL、出典表記、独自解説を保持。全肢解説とは表示せず `official-summary` と明示。
