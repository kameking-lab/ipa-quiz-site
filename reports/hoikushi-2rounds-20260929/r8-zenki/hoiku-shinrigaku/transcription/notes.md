# 転記・裁定メモ — 令和8年度前期・地域限定保育士試験「保育の心理学」（r8-zenki / hoiku-shinrigaku）

## 機械差分（passA vs passB）

- `subj6.passA.txt`（PyMuPDF `get_text("text")`, 424行）と `subj6.passB.txt`（`get_text("blocks")`
  再構成, 771行）を全文読み合わせた。
- passBは行間に空行が多く挿入されている（ブロック単位の再構成のため）だけで、**本文・選択肢・
  組み合わせ表・語群の文字列は一字一句完全に一致**している。数値、否定語（「〜ない」「〜ではない」
  等）、人名の表記（例: シュテルン(Stern, W.)、ゲゼル(Gesell, A.L.)、ピアジェ(Piaget, J.) 等）、
  組み合わせの○×パターンもすべて一致し、食い違い箇所はゼロだった。
- したがって元PDFの追加ページ再抽出・`pdftotext -layout`との突き合わせは不要と判断した。
- `final.json` 作成前に、`passA.txt`・`passB.txt` と `final.json` の `question`/`choices` を
  再度目視で1問ずつ突き合わせ、転記ミス（全角/半角、句読点、数字の選択順）がないことを確認した。

## 表記ゆれ・整形の方針

- 全角数字・カタカナ表記（Ａ〜Ｅ等）は原文どおり使用。
- 「（　Ａ　）」のような空所記号はそのまま `question` 本文に含めた。
- 語群（【語群】）はA〜D等の記号に対応する形で `question` 本文に列挙する形で含めた
  （選択肢自体は「組み合わせ」の1〜5をそのまま `choices` とした）。
- 表形式の組み合わせ表（問20など、A/B/Cが縦に並ぶ形式）はMarkdown的な列挙に変換して
  `question` に含めた（画像ではなくテキストなのでHOLD対象ではない）。

## HOLD / PARTIAL_HOLD 判定

- 全20問とも、図・写真・楽譜・グラフへの依存はなし（すべて文章・選択肢・組み合わせ表のみ）。
  よって **HOLDは0件**。
- 公式正答（`official-answers.json` → `r8-zenki` → `保育の心理学`）は全問で一意の値が入っており、
  問題文の「○つ選びなさい」の指示数（1/2/3）と正答の要素数が全問で一致することを確認した
  （例: 問1「3つ選びなさい」↔ official-answers "1,2,5"＝3件、問13「2つ選びなさい」↔ "1,2"＝2件）。
  複数解釈の余地を示す記載も問題文・PDF双方に見当たらなかったため **PARTIAL_HOLDは0件**。

## 起稿・査読プロセス

- 起稿: `claude -p` を2バッチ（問1-10 / 問11-20）でツールなし（`--allowedTools ""`）呼び出し。
  出典URL・法令条文の推測は禁止する指示を入れた。生出力は
  `explanations/draft-batch1.receipt.json` / `explanations/draft-batch2.receipt.json` に保存。
- 査読: 起稿とは別プロセスの `claude -p`（`--allowedTools "WebSearch,WebFetch"`）で、
  発達心理学の学説・実験・人物帰属（ピアジェ、ヴィゴツキー、エリクソン、ボウルビィ、ポルトマン、
  パーテン、マーシア、セルマン等）を中心にWebSearch/WebFetchで一次資料・信頼できる教科書的記述と
  突き合わせ、主張（文）単位でPASS/FIX/HOLDを判定。FIXは修正文を提示させた。
  生出力は `explanations/review.receipt.json` に保存。
- FIXが出た文は該当バッチのみ別セッションで再査読し、全てPASSになるまで繰り返した
  （詳細は REPORT.md 参照）。
