# 転記メモ — r8-zenki / shakai-fukushi（社会福祉）

## passA / passB 機械差分の結果

`subj5.passA.txt`（PyMuPDF get_text("text")）と `subj5.passB.txt`（get_text("blocks") 再構成）を
Python (`re.sub(r'\s+','')` で正規化 → `difflib.SequenceMatcher`) で突き合わせた。

- 問1本文の開始位置（`問1次のうち、社会福祉の基本理念`）以降、20問の全文を比較した結果、
  検出された差分は **10か所すべてがページ番号（フッター）の出現順のズレのみ**（例:
  `...4×○○×5××○○2問2次の【Ⅰ群】...` vs `...4×○○×5××○○1問2次の【Ⅰ群】...` — これは
  ページ番号「2」の抽出位置がpassAでは次ページ見出し直前、passBでは前ページ内という
  レイアウト差によるもので、問題文・選択肢の文言そのものには一切差異がない）。
- 問題文・選択肢・組み合わせ表の文言は passA/passB で完全一致。よって元PDF個別ページの
  再抽出は不要と判断した。

## 目視突き合わせ（最終確認）

`final.json` 執筆前に、上記の正規化済みテキストと `final.json` の `question`/`choices` を
1問ずつ目視で再照合した。誤字・脱字・句読点の相違なし。

## 表記ゆれ・注記

- 選択肢が「○×の組み合わせ」形式の問題（問1, 6, 9, 10, 12, 14, 16, 17, 20）は、`question` に
  Ａ〜Ｄ（または問10のみＡ〜Ｃ）の記述を箇条書きで含め、`choices` は原文の「（組み合わせ）」欄の
  1〜5番の○×パターンをそのまま採用した（例: "Ａ○ Ｂ× Ｃ○ Ｄ○"）。
- 問2は【Ⅰ群】Ａ〜Ｄと【Ⅱ群】ア〜エの対応表形式。`question` に両群の記述を含め、`choices` は
  「（組み合わせ）」欄の1〜5番（ア〜エの並び）をそのまま採用。
- 問3・問18は空欄補充（Ａ〜Ｃ／Ａ〜Ｄ）の組み合わせ表形式。`question` に本文（空欄はそのまま
  （　Ａ　）等の表記で残す）を含め、`choices` は組み合わせ表の1〜5番の語句をまとめて1つの
  文字列にした（例: "Ａ：福祉的方法／Ｂ：平均的な生活水準／Ｃ：社会福祉"）。
- 問13は法律の制定順を問う並び替え問題。`choices` は原文の1〜5番の並び（例: "Ａ→Ｂ→Ｄ→Ｃ"）を
  そのまま採用。
- 問15は「適切なものの組み合わせ」を２つ選ぶ形式だが、選択肢自体（1〜5）が2文字の組み合わせを
  提示する単一選択（`requiredSelections: 1`、公式正答は単一値 "3"）。
- 図・写真・楽譜・グラフに依存する設問はなし。HOLD対象なし。
- 全問、公式正答が単一の値または単純なカンマ区切りで一意に定まっており、PARTIAL_HOLD対象もなし。
