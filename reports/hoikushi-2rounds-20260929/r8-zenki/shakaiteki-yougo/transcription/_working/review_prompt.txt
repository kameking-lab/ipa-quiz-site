## 判定方法
起稿案の各選択肢の説明文を、**主張（文）単位**で PASS / FIX / HOLD 判定してください。
- PASS: 原文・公式正答・一次資料と整合し、事実誤認や推測の混入がない
- FIX: 一部に誤り・未確認の推測（条文番号・統計数値・年号など）が含まれる。修正後の文言を
  必ず提示すること。修正は一次資料で確認できた事実のみに基づくこと。確認できない具体的数値・
  条文番号は削除するか、一般的な表現に置き換えること。
- HOLD: 一次資料でも真偽を確認できない、または図表・統計の詳細が必要で本文だけでは検証不能

事例問題（問9・問10）は対人援助の一般原則の観点でよいが、断定的すぎる記述（虐待の即断、
面会の一律禁止を正当化する等）がないか確認すること。

officialAnswer との整合性も確認すること:
- 問1:[3] 問2:[4] 問3:[5] 問4:[3,5] 問5:[5] 問6:[3,5] 問7:[5] 問8:[4] 問9:[2] 問10:[4]

## 出力形式
説明文や前置きなしで、以下のJSON形式のみを出力してください（コードブロック不要）:

{
  "questions": [
    {
      "number": 1,
      "verdicts": [
        {"choiceIndex": 1, "status": "PASS", "finalText": "確定した説明文（PASSならほぼ起稿案のまま、FIXなら修正後の文）"},
        {"choiceIndex": 2, "status": "FIX", "finalText": "修正後の説明文", "reason": "何を修正したか"},
        ...
      ],
      "lawSensitive": true,
      "evidenceUrls": ["実際にWebFetch/WebSearchで確認した一次資料のURL"],
      "partialHold": false,
      "partialHoldReason": null,
      "questionLevelNote": "任意。公式正答との不一致など問題があれば記載"
    },
    ... number 2〜10
  ]
}

各問題で choiceIndex は1始まりで choices/choiceExplanations の順序に対応します。
