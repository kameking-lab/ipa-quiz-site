## コミット保存先の制約

共有リポジトリで`git add`を実行したが、`.git/index.lock`作成が読み取り専用ファイルシステム（EROFS）で拒否された。承認要求や権限変更は行っていない。共有ブランチへの直接コミットは未実施。一時Git領域に同じ親コミットを持つ仕上げコミットを作成し、`/tmp/gyosei-finish.bundle`として保存する。監督役はbundleから取り込んでpushできる。共有作業ツリーには全変更を残す。

取り込み例（作業ツリーが安全に退避・整理済みの監督側で実行）：

```sh
git fetch /tmp/gyosei-finish.bundle refs/heads/gyosei-finish:refs/heads/gyosei-finish
git cherry-pick gyosei-finish
```
