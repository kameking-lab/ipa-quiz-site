## 問115 バイステックの援助関係：PASS

根拠：[Biestek, *The Casework Relationship* 原著の公開画面、七原則一覧](https://www.scribd.com/document/656445622/Biestek-The-Casework-Relationship)、[IFSW 2018年倫理原則6.1〜6.2](https://www.ifsw.org/global-social-work-statement-of-ethical-principles/)。原著の長文は転載しない。公開画面で原則の対応を確認し、秘密保持の例外は現行IFSW倫理原則でも確認。

1. 誤り。非審判的態度はクライエントを裁断・非難しない関係であり、ワーカーが責任の承認・不承認を決めることではない。
2. **正答。** 自己決定はクライエント自身が選択・決定する権利を尊重し、ワーカーがその判断を支えること。
3. 誤り。統制された情緒的関与はワーカー側がクライエントの感情を理解し適切に応答することで、クライエント自身による感情の意識化を定義としない。
4. **正答。** 意図的な感情表出は、否定的な感情を含め、クライエントが感情を表現できるよう支える。
5. 誤り。秘密保持は絶対無条件ではない。自己・他者への害の危険や法定制限がある場合に例外があり、限界を本人に伝える。

## 問116 ソーシャルアクションとアウトリーチ：PASS

根拠：[厚労省助成の社会福祉士養成課程報告書、実習ガイドラインp.70とソーシャルワーク演習ガイドラインp.112](https://www.mhlw.go.jp/content/12200000/000651532.pdf)。当事者の居場所に出向くアウトリーチ、政策・制度的な不足に対するソーシャルアクションの説明を確認。

1. 誤り。個々の選好に合わせた支援の設計を中心とする記述ではなく、同様の人々への訪問と行政への働きかけがある。
2. 誤り。他機関への紹介・送致の描写はない。
3. **正答。** 就労機会の制度的不足を当事者と共有し、行政に協力を求めて社会的変更を図る。
4. 誤り。対象者を採否や緊急度で選別するスクリーニングではない。
5. **正答。** 外出困難な人々の自宅へ出向いてニーズを聴き取っている。

## 問117 面接技法：PASS

根拠：[厚労省「ソーシャルワークの方法」の面接技法図](https://www.mhlw.go.jp/content/12203000/000515602.pdf)、[厚労省職業能力開発分野の面接技法教材の「明確化」「要約」説明](https://www.mhlw.go.jp/seisakunitsuite/bunya/koyou_roudou/jinzaikaihatsu/jobcard_system/jobcard_koshu/pdf/text_seido-H3010-1.pdf)。後者はキャリア面接の教材なので、社会福祉の技法図と併読して一般の面接操作のみ参照。

1. 誤り。明確化は曖昧な内容・感情の意味を確かめることで、賞賛とは異なる。
2. 誤り。閉ざされた質問は回答範囲を絞り、自由度を増やすものではない。
3. 誤り。共感的応答はクライエントの経験・感情を理解して応じるもので、ワーカーの価値を教示することではない。
4. **正答。** 要約は語られた要点をまとめ、クライエントがそれまでの内容を整理・確認できるようにする。
5. 誤り。焦点化は扱うテーマを絞って検討する技法であり、話したくないテーマの回避を目的としない。

## 問118 Aさんの事例検討：PASS

根拠：[厚労省の相談支援研修検討会議事録（本人中心の意思決定と聞き取り）](https://www.mhlw.go.jp/stf/shingi2/0000131629_00001.html)、[厚労省の認知症ケア検討会議事録（本人の困りごと・意向・希望）](https://www.mhlw.go.jp/stf/shingi2/0000164165.html)、[厚労省事例検討会の参加環境資料](https://www.mhlw.go.jp/content/12200000/001373009.pdf)。事例の二つの行動から認知症等の医学的診断や独居不能を決めつけない。

1. 誤り。近隣住民の困りごとの確認自体は今後あり得るが、Aさんに関する分析の第一焦点を近隣の都合へ移す。
2. **正答。** 支援者の見立てにAさんの強みと現状理解が入っているか問い、事例分析に必要な情報を補う。
3. 誤り。管理人の考えを本人の意向に先行させる。同行していた事実は確認できても、管理人の方針で支援を決めない。
4. 誤り。独居継続不能と未評価のまま断定し、住まいの変更を促すのは早い。
5. **正答。** Aさん自身が現状をどう理解し、どう暮らしたいかを把握するのが本人中心の分析である。

## 問119 事例提供者が安心して話せる場：PASS

根拠：[厚労省の事例検討手法資料、PCAGIP法による安全な雰囲気と事例提供者の目的の確認](https://www.mhlw.go.jp/content/12200000/001373009.pdf)、[Social Work Englandの監督・省察の安全な場の説明](https://www.socialworkengland.org.uk/news/the-vital-role-of-social-work-supervision/)。後者は他国の専門職実務例であり、日本の法的義務とは扱わない。

1. 誤り。本人参加は目的と同意に応じて検討し得るが、職員からの依頼による職員向け事例検討で必須条件ではない。
2. 誤り。同年数者だけでは多角的な経験や支援を得る構成にならず、必須でもない。
3. 誤り。時間枠と進行を設け、必ず単一結論が出るまで続けるものではない。
4. 誤り。安全な事例資料は問題共有に使える。口頭のみに限定する根拠はない。
5. **正答。** 発表したCが批判されていると感じて防衛的にならないよう、安全な雰囲気と建設的なコメントの仕方に配慮する。

## 問120 外国籍住民を含む最初の場づくり：PASS

根拠：[厚労省の地域共生社会検討会議事録（多文化共生で外国人と日本人の相互理解、場づくり）](https://www.mhlw.go.jp/stf/newpage_08828.html)、[厚労省の外国人雇用対策検討会議事録（当事者を含む関係者参加）](https://www.mhlw.go.jp/stf/newpage_19242.html)、[厚労省助成の社会福祉士養成課程報告書の地域組織化・合意形成の説明](https://www.mhlw.go.jp/content/12200000/000651532.pdf)。多文化共生についての具体策は、関係者と当事者の課題認識から作る。

1. 誤り。外国籍の子どもの問題と学校対策に早く限定し、家族や住民の相互の課題をまだ共有していない。
2. **正答。** 在留外国人を当事者として含め、学校・自治会等が相互の声を聴いて問題を共有する懇談の場を先に設ける。
3. 誤り。一方向の日本人向けパンフレットでは、外国人家族の声や地域住民の希望を相互に把握できない。
4. 誤り。企業に解決を丸投げし、地域の多主体・当事者との話し合いを経ない。
5. 誤り。交流会は有効な後続施策になり得るが、何が障害で何を望むか共有する前の第一手としては早い。
