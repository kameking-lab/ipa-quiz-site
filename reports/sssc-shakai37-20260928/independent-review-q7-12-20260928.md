## 問7 エピソード記憶：PASS

根拠：[米国心理学会の記憶に関する教材](https://www.apa.org/ed/precollege/topss/lessons/memory.pdf)、[同会のエピソード記憶の定義](https://dictionary.apa.org/episodic-memory)。

1. 誤り。計算中の途中結果の保持・操作は作業記憶。
2. 誤り。登録まで電話番号を一時的に保持するのは短期記憶・作業記憶。
3. 誤り。カナダの位置という一般的知識は意味記憶。
4. 誤り。自転車の運転技能は手続き記憶。
5. **正答。** 昨夜自分が食べた夕食という、時と自己体験に結びつく出来事の記憶。

## 問8 社会的抑制：PASS

根拠：[米国心理学会の社会的抑制の定義](https://dictionary.apa.org/social-inhibition)、[原著者Zajoncによる社会的促進研究](https://doi.org/10.1126/science.149.3681.269)。他者の存在が課題遂行に及ぼす影響を、期待効果・同調・集団極性化・対人距離と分ける。

1. 誤り。上司の期待によって業績が変わるのは期待効果・自己成就的予言に近い。
2. 誤り。多数派に合わせて賛成するのは同調。
3. 誤り。集団討議後に結論が極端化するのは集団極性化。
4. 誤り。至近距離への不快感は対人距離の問題。
5. **正答。** 他者の存在や視線によって作業効率が下がる例が社会的抑制。

## 問9 エリクソンの青年期：PASS

根拠：[Erikson Instituteによる理論史](https://www.erikson.edu/about/history/erik-erikson/)、[NCBI Bookshelfの発達段階整理](https://www.ncbi.nlm.nih.gov/books/NBK556096/)。

1. 誤り。基本的信頼対不信は乳児期。
2. **正答。** 同一性対同一性混乱は青年期の心理社会的危機。
3. 誤り。勤勉性対劣等感は学童期。
4. 誤り。原著の自発性の対概念は罪悪感で、青年期ではなく遊戯期・就学前期。選択肢の羞恥心は自律性の対概念側に属する。
5. 誤り。ジェネラティビティ対停滞は成人期。

## 問10 レジリエンス：PASS

根拠：[米国心理学会のレジリエンスの定義](https://www.apa.org/topics/resilience)。

1. 誤り。ストレスを生む出来事はストレッサー。
2. **正答。** 逆境や強いストレスを経験しても適応・回復していく過程や力を指す。
3. 誤り。不快情動を意識的に低減する方略は感情調整・コーピングの説明。
4. 誤り。外傷体験が現在起こっているように感じるのは再体験症状。
5. 誤り。人間関係での支え合いは社会的支援。レジリエンスを支える要因ではあるが同義ではない。

## 問11 マイクロカウンセリングの初期応答：PASS

根拠：[開発者Iveyのマイクロカウンセリング資料](https://www.allenivey.com/microcounseling)、[米国心理学会の定義](https://dictionary.apa.org/microcounseling)、[Penn State Universityの面接技法教材](https://courses.worldcampus.psu.edu/welcome/rhs301/001/content/01_lesson/06_page.html)。

1. 誤り。相談者の負担感を十分聴く前に対処法を指示している。
2. 誤り。行動の評価から始めると、語りを妨げる。
3. 誤り。支援者自身の経験を同一視し、相談者の固有の状況をまだ把握していない。
4. **正答。** 開かれた質問で状況を詳しく聴き、相談者の語りを促す初期応答。
5. 誤り。記録の都合を優先し、相談者の気持ちや問題の探索を始めていない。

## 問12 認知行動療法：PASS

根拠：[Beck InstituteのCBT説明](https://beckinstitute.org/about/understanding-cbt/)、[同研究所の認知モデル](https://beckinstitute.org/wp-content/uploads/2024/05/Cognitive-Model.pdf)、[精神分析家による自由連想の説明](https://pubmed.ncbi.nlm.nih.gov/36782042/)。

1. 誤り。「生の欲望」や不安をあるがままにして行動するという説明は森田療法に近い。
2. 誤り。自由連想法は精神分析に由来する。
3. 誤り。抑圧された無意識を洞察することを主軸とするのは精神分析的な方法。
4. **正答。** 思考・行動の適応的な変化に働きかける。
5. 誤り。認知行動療法は行動だけでなく思考、感情、身体反応の変化も扱う。
