# 山口県ふぐ処理師・学科（公開前）

令和8年は19大問・100解答欄、令和7年は18大問・100解答欄。演習用JSONは**原本の通し解答欄番号**を `qNumber` として1～100で保持する。200原大問という意味ではない。

元の大問番号・科目は `subject`、大問全文は `originalContent.body`、一覧は `*-original-groups.json` に残す。各欄の画面でも元の大問と語群・対応表を提示し、解答する欄番号を指定する。○×は選択肢ア=○、イ=×に対応し、`officialAnswerNumber` は原本の○・×・カナを保持する。語群は原本のカナと順序を使う。

令和8年解答欄90～95は同一の鑑別図を共有し、全分岐をテキストでも保持する。法令・通知・可食部位の解説は各出題時点の内容。令和7年欄8は原本・公式正答にある厚生労働大臣を採点に用い、現行の権限配分への読み替えは行わない。

資格台帳はready-to-ingest。公開への切替と独立レビューは監督役が別途行う。
