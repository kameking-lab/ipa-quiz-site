# 機械保全技能検定 2級 機械系保全作業 学科・未公開ステージング

実施機関は公益社団法人日本プラントメンテナンス協会（JIPM、厚生労働大臣指定試験機関）。
2026-11-06に[公式の過去問ページ](https://www.kikaihozenshi.jp/questions/)を通常GETで確認した。
2級学科の直近2回は2024年度第2回（2024-12-15実施）と2025年度第2回（2025-12-14実施）。
各回の問題PDFと正解PDFを取得し、各50問・計100問を収録した。JAVADA版は使っていない。実技試験は対象外。

## 形式

両年度の表紙に「問題数：50題」「真偽法（問1〜問25）」「多肢択一法（問26〜問50）」とある。

- No.1〜25は真偽法。`answerFormat: "true-false"`。選択肢は`{"〇": "正しい", "×": "誤り"}`。
- No.26〜50は四肢択一。`answerFormat: "four-choice"`。選択肢はア〜エで、本文は原本どおり。
- `officialAnswer`は正解PDFの印字記号（〇・×・ア〜エ）。

## 未公開の扱い

`manifest.json`と各問の`publicAllowed`は常に`false`。`publicationStatus`は`staging`、`needsReview`は`true`。
ExamCode、公開レジストリ、通常ローダー、`public/`には接続しない。`index.ts`は編集・検証専用。
独立レビューは未実施（`independentReview: "pending"`）。

## 転記方法

PDFにはテキスト層があるが、出現順が印刷順と一致しない。たとえば2024年度p.2では、No.7以降の本文がNo.1〜6より先に並ぶ。
そのため行の座標を取得し、問番号のy範囲ごとに本文と選択肢を組み直した。全ページを描画したPNGと目視照合している。
改行と空白を整理し、全角英数字は半角にそろえた。等号の全角・半角と不等号「≧」は原本どおり。
上付き・下付き・上線は次のように表記し、原本の体裁は画像に残した。

- min⁻¹
- h_f
- X̄

2025年度No.17の表は本文末尾に［表］としてテキスト化した。

図・表・特殊表記に頼る10問は、3倍で描画したページから問題全体を切り出し、ロスレスWebPで`images/`に保存した。

- 2024年度：No.47・48・50
- 2025年度：No.3・17・27・30・47・48・50

`hasImage`、`images[].sha256`、代替テキストを付けている。

## 正答と解説

正答は正解PDFの表をセル座標で読み取った。描画画像でも照合し、問題データとは別の`official-answers.json`に保存した。
`source-audit.json`には次を記録した。

- 各問のページ・切出し範囲
- 本文ハッシュ
- 正答の一致
- 原本4PDFのSHA-256

解説は過去問AIの独自作成で、市販解説や解答サイトの文章は使っていない。全選択肢に解説を付けた。
真偽法では、〇と×のどちらを選んだ場合も理由を示す。計算問題は再計算して確認した。

- 2024年度No.47：滑車
- 2024年度No.50：はめあい
- 2025年度No.3：並列抵抗
- 2025年度No.4：同期速度
- 2025年度No.17：範囲R
- 2025年度No.47：はりの反力

法令・JIS等に関わる問題は`legalContextDate`に試験実施日を入れ、説明は出題時点の内容とした。
公式の基準日は示されていないため、`lawReferenceDate`は`null`。

`sourceTextSha256`は`sha256(UTF-8(NFC(JSON.stringify({question, choices}))))`で求める。改変の検知に使う。
