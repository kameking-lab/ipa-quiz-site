# 自動車整備士学科・最新2回の原問原稿

令和8年度第1回（2026年10月4日）の筆記250原問と、令和7年度第2回（2026年3月22日）の筆記360原問を対象とする。科目別の直近2回ではなく、登録試験全体の最新2回に実施された全科目である。国交省の技能検定とは区別する。

同じ資格・年度・回・科目・公式問番号を1原問として数える。二級シャシは30問。一級小型の2026年5月10日口述2原問は補助資料に分離し、筆記610の母数に加えない。

## データと取込

latest-two.jsonは17筆記科目の原稿と口述補助を保持する。draft-types.tsは既存Questionの本文・肢・説明・出典・図表の型に合わせる。資格とライセンスの登録は統合担当が行う。科目ごとに問番号が1へ戻るため、IDと科目を保持し、二輪・車体・一級小型などを同じ問題冊子として混在させない。

index.tsの全データにAutomotiveDraftBundle型を直接指定してTypeScriptで検査する。getAutomotiveWrittenDraftsで年度・回・科目を指定でき、gradableOnly=trueは上記2件を除外する。本文の型は既存Questionから継承し、登録前の資格コードや供給元ライセンスを既存の別資格へ偽装しない。本PRはsource-specific原稿と取込用ライブラリを実装し、公開レジストリへの登録は含めない。

図表依存問にはsourcePageReferencesとfigurePageReferencesを付け、公式PDFの物理ページへ直接参照できる。必要な原本ページはfigures/にWebPで同梱し、sourceFigureAssetsに紐づける。加工は検証済みPNGからWebPへの形式変換のみで、図の内容を生成・修復していない。figure-assets.jsonに画像寸法・ハッシュ・対応原問を記録する。元PDFと高解像度PNGも制作ワークスペースに保存している。

permissionVerified=false、publicGo=0は、制作側が供給元の許諾を確認済みと捏造しないための記録である。運営者は掲載可否を自身で扱うと明示し、原典取得・原稿制作・draft PRを指示した。本タスクは本番マージ・デプロイを行わない。

## 検査

validate-automotive-drafts.mjsは母数、原問ID重複、公式問番号、公式正答、全4肢と全肢説明、図表ページ、分類、全員正解の特殊扱いを検査する。validate-automotive-drafts.test.mjsは重複・欠肢・誤答・出典範囲外・架空の許諾フラグを拒否する負例を含む。

validation.jsonには実際の完成数、採点対象数、図表数、原稿ハッシュを記録する。作業途中稿を完成数に含めない。

再検査は `node scripts/automotive/validate-automotive-drafts.mjs data/qualification-staging/automotive/latest-two --require-manuscripts-complete` 。このフラグは原稿610件の整備を確認する。`--require-complete`は分類不整合の1件を検出して終了コード2になる。原稿完成と通常出題可能を混同しない。
