## 画面とデータの構成

`capacitor.config.ts` の `webDir` は `dist`。`server.url` は指定していない。起動時は `src/main.tsx` の `shouldOpenWebHome()` が接続状態を確認し、オンラインなら `https://www.kakomon-ai.jp/` へ `location.replace()` する。ホーム・オンライン演習・チワワ育成などは本番Webの画面を使う。

`?local=1` とオフライン・Web遷移失敗時は同梱React画面を表示する。この画面はWebの `QuizPlayer`、`ExamQuestionPlayer`、教材リーダーとチワワ関連処理をインポートするため、共有コードの更新が必要。問題・解説本文は同梱せず、既存のダウンロード処理で保存する。資格一覧と件数・リビジョンの索引は同梱する。
